## Как повторить

Скачать указанные три таблицы, README и manifest из среза в `/tmp/`, добавив к именам префикс `glama-2026-11-02-`. Затем из корня aicom выполнить:

```sh
python3 artifacts/glama-draft-check-2026-11-02/check.py > artifacts/glama-draft-check-2026-11-02/result.json
```

Проценты по числителям и знаменателям справки дополнительно сохранены в `arithmetic.json`.

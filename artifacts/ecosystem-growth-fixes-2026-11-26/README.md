## Attested Memory

На странице для разработчиков пример выводит ID новой записи. При `pending` он ждёт решения оператора и повторно проверяет доступность по команде пользователя. Тест проходит через локальные Gateway, Personal API и Memory Market. Если пользователь нажимает Enter до одобрения, запрос выдачи доступа не уходит. После одобрения проходят выдача доступа, чтение, отзыв и контрольный HTTP 403.

Прошли пять тестов прокси. Тот же пример отдельно прошёл с опубликованным Python wheel `attested-memory==0.3.0`. Страница изменена в локальном исходнике.

OpenCode 2.4.1 дважды вызвал один синтетический MCP-инструмент через локальный провайдер: напрямую и через Code Mode. Оба результата дошли до следующего модельного запроса и заняли **44 байта UTF-8 / 16 токенов o200k_base**.

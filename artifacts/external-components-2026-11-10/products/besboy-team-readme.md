# Team Memory OS

Система знаний команды: поиск по внутренним документам, ответы с источниками, память решений и аудит.

## Запуск

```powershell
python app.py
```

Открыть http://localhost:8002. Зависимости не нужны: Python 3.10+.

Docker: `docker compose up --build`.

## API

- `GET /api/documents` — документы базы;
- `GET /api/memories` — сохранённые решения;
- `POST /api/ask` — задать вопрос;
- `GET /api/questions` — история ответов;
- `GET /api/audit` — журнал запусков;
- `GET /api/export` — экспорт вопросов и ответов.

Пример:

```powershell
$body = @{query='Как проходит онбординг нового клиента?'} | ConvertTo-Json
Invoke-RestMethod http://localhost:8002/api/ask -Method Post -ContentType 'application/json' -Body $body
```

## Демонстрация

1. Ввести: `Как проходит онбординг нового клиента?` — ответ с источником.
2. Ввести: `Как точно решить неизвестную задачу?` — `needs_review=true` и объяснение.
3. Открыть «База знаний» — документы и память решений.
4. Открыть «Аудит» — история запросов.
5. Нажать «Экспорт» — JSON-файл.

## Архитектура

Web-панель → Python API → SQLite (`documents`, `memories`, `questions`, `audit_runs`) → поиск по источникам → JSON quality gate → ручная проверка → аудит.

В демо используется воспроизводимый локальный адаптер поиска без внешних ключей. В production его можно заменить на embeddings/LLM без изменения API-контракта.

## Мини-экономика

Поиск ответа вручную занимает 10 минут, с системой — 2 минуты. Для 100 вопросов: 1000 → 200 минут, экономия 800 минут, или 13,3 часа.

# Ответы MCPBeat и Internet Archive — 25 ноября 2026

## EasyGerber и MCPBeat

Денис из MCPBeat подтвердил исправление. По его словам, каталог сохранял адреса, исчезнувшие из новой версии записи MCP Registry. Для EasyGerber это оставило в сниппетах `/api/mcp/account`, который требует входа. MCPBeat исправил обработку удалённых адресов и сообщил, что убрал около 1 400 устаревших записей по всему каталогу. Число и поведение на следующих обновлениях пока известны со слов оператора. [Исходная диагностика 24 ноября](../external-mentions-2026-11-24/further-leads.json)

В свежем публичном поисковом снимке страницы от 25 ноября все пять конфигураций, для Claude Code, Claude Desktop, Codex, Cursor и VS Code, указывают на `https://www.easygerber.com/api/mcp`. В секции подключения пять гостевых URL и ни одного `/account`. Прямой GET страницы получил HTTP 403 от Cloudflare, а более старый снимок показывает прежние сниппеты. [Карточка MCPBeat](https://mcpbeat.com/mcp-servers/easygerber/easygerber/)

Прямой GET официального реестра независимо подтвердил историю. Версия `0.1.0` содержит только `/api/mcp/account`. Последняя версия `0.1.1` содержит только гостевой `/api/mcp`. Собственная документация EasyGerber по-прежнему описывает оба режима. По правилам MCPBeat, изложенным Денисом, отдельный адрес для входа появится в каталоге, если EasyGerber опубликует его вторым remote в актуальной записи. [Официальный MCP Registry](https://registry.modelcontextprotocol.io/v0.1/servers?search=easygerber) · [Документация EasyGerber](https://github.com/EasyGerber/easygerber-agent-plugin#start-without-signing-up)

Конкретный внешний результат для отчёта — исправление пути установки в стороннем каталоге после нашего сообщения. Дополнительный эффект, заявленный оператором, относится ко всему каталогу. Здесь нет проверки новых подключений клиентов.

## Open Library и AIMarket Hub

Internet Archive, тикет 1697510. Команда отказалась запускать Hub и участвовать в предложенном пилоте. Sapphire направила к общедоступному API и сообщила, что Open Library не согласовывает отдельные случаи использования. Запуск Hub партнёром и квитанция от партнёра в этом случае не состоялись.

Один прямой GET ISBN `9780140328721` вернул издание `OL7353617M`, *Fantastic Mr. Fox*, издатель Puffin, дата из ответа API — 1 октября 1988 года. Это подтверждает доступность исходной операции чтения метаданных. [Ответ Open Library API](https://openlibrary.org/isbn/9780140328721.json) · [Карточка издания](https://openlibrary.org/books/OL7353617M)

Правила API ориентированы на пользовательский поиск книг и просят кэшировать ответы и идентифицировать приложение. Опубликованные лимиты составляют один запрос в секунду без идентификации и три с идентифицированным `User-Agent`. Для объёмной обработки предусмотрены ежемесячные выгрузки. Если AIMarket проверяет свою квитанцию на этом примере, роль подписанта принадлежит AIMarket, а Open Library выступает источником метаданных. [Правила использования](https://openlibrary.org/developers/api#usage) · [лимиты](https://openlibrary.org/developers/api#rate-limits) · [выгрузки](https://openlibrary.org/developers/api#bulk-access)

# Задание коллеге по публикации mcp-token-cost

Публичный README `alexar76/mcp-token-cost` всё ещё говорит, что клиент отправляет все определения MCP с каждым запросом. Готовый патч уточняет, что проект считает полный список, а набор переданных схем зависит от клиента. Он обновляет README, подсказки CLI и отчёты text, Markdown и HTML. [Публичный репозиторий](https://github.com/alexar76/mcp-token-cost) · [Патч](mcp-token-cost-full-list.patch) · [Замер OpenCode](opencode-result.json)

1. Применить патч в обычной рабочей копии `alexar76/mcp-token-cost`. Он соответствует локальному коммиту `e0fb4ce84` в `aicom`. Проверено командой `git apply --check` на публичной ревизии `ca295cb18663f401bee1184181b655621e35e2a5`.
2. Запустить `npm test` на Node 22. В рабочей копии `aicom` прошли 40 тестов. Проверить, что в пользовательских отчётах итог называется стоимостью полного списка. Сценарии цены относятся к запросам, которые отправляют этот список.
3. Опубликовать изменения в `alexar76/mcp-token-cost` штатным способом и вернуть URL итогового коммита или PR. Если исходники выпускаются из монорепозитория, включить тот же патч в ближайшую синхронизацию этого репозитория.

В патче семь файлов `mcp-token-cost`. Выкладка калькулятора `modelmarket.dev` и quickstart `attestedmemory.net` идёт отдельными операциями на их хостинге. Для них этот патч не нужен.

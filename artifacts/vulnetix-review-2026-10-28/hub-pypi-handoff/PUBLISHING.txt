ПРОВЕРКА БЕЗ ПУБЛИКАЦИИ
В папке hub-pypi-handoff:
  python3 publish_prepared.py
Это локальная проверка, без сети и чтения credentials.
  python3 verify_release.py --availability --report availability-now.json
Только публичные GET: версия свободна либо уже опубликован именно этот wheel.
Конфликтующий файл означает остановку. Не перезаписывать релиз и не менять
версию вручную в архиве.

ПУБЛИКУЕТ ТОЛЬКО НАЗНАЧЕННЫЙ КОЛЛЕГА
Нужны Python 3.11+, uv и права издателя aimarket-hub экосистемы alexar76.
Издатель предоставляет UV_PUBLISH_TOKEN через свой способ хранения секретов.
Не вставлять значение в чат, git, архив, инструкции или историю shell.
Команда только для издателя:
  python3 publish_prepared.py --upload-to-pypi
Она проверяет файлы, загружает единственный точный wheel в production PyPI
и скачивает опубликованный wheel для повторной проверки.
GitHub, Gitea, теги и deployment эта команда не меняет.

ПОСЛЕ ПУБЛИКАЦИИ
  python3 verify_release.py --published --report published-verification.json
Успех: published_verified, PASS, exit code 0. Проверяются весь SHA-256, metadata,
каждый Python-файл, четыре модуля исправления и RECORD.
not_published или error не являются успехом. При задержке PyPI повторить
только проверку; не загружать файлы повторно вслепую.

НАСТРОЙКА ПОСЛЕ УСТАНОВКИ
Публикация сама не меняет действующие серверы. На hub задать
AIMARKET_ORACLE_PAID_TIER_CREDENTIALS: JSON, связывающий точный invoke URL
каждого оракула с именем отдельной переменной секрета (secret_env).
На оракуле то же значение задаётся как ORACLE_PAID_TIER_SECRET.
Нужны настройки с обеих сторон. Секреты не входят в этот архив.
Документация в исходниках: aimarket-hub/docs/oracle-paid-tier.md.
HTTPS — по умолчанию. HTTP требует allow_http=true для конкретного адреса.
Бесплатные и sandbox-вызовы остаются в бесплатном tier; комиссия маршрутизации
не даёт права на платные вычисления. Credential не следует за редиректом.

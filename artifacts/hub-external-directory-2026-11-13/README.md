# ModelMarket external x402 directory rollout

ModelMarket moved from `618ea971f7b6` to `60b41cad9c31` on 13 November 2026. The release added the public [external directory](https://modelmarket.dev/ai-market/v2/external-services) and linked the cards from the [ModelMarket home page](https://modelmarket.dev/#external-directory). CoinMarketCap, Tavily and Laso point to the providers' own documentation. The directory tells buyers to use their own wallet and pay the provider directly.

The offline build overlaid four reviewed files and kept all 76 Python distributions and 129 Debian package entries. Both images opened disposable copies of the Hub and channel ledgers with zero migrations. They returned identical callable manifest and search results, bridge settings, and 36 observed routes. The candidate showed the directory in five languages and omitted it on an independently named Hub. The backend suite passed 96 tests and the terminal suite passed 19. [Build and copied-ledger smoke](prepare.log) · [Terminal tests](terminal-tests.log)

The rollout backed up both ledgers and verified Hub and THEMIS health. Live API checks confirmed the three provider records and searches, budget and Hub-scope filters, five locale dictionaries, 286 callable manifest entries, and zero external directory records in callable matches, the manifest, or the observed-seller list. The existing payment bridge still reported zero USDC and its prior spending limits. The publisher payout remained paid with one reservation, one paid posting, and no pending payouts. The resumed worker exited successfully. The installed CMC verifier also confirmed the prior finalized 0.01 USDC receipt and rejected the wrong nonce.

Оба обычных web-повтора выполнены без JavaScript, cookie/CAPTCHA handling или дальнейшего retry. После нового Root-контроля Obsidian REST 403/CORE 0 этот worker не делал ни одного `api.github.com` GET. Root отдельно разрешил открытые GitHub web/raw и опубликованный artifact host самого издателя; использованные URL и `access_method` сохранены раздельно. Никаких сторонних proxies/mirrors, смены IP, аккаунта или авторизации не использовалось.

Старый `X-RateLimit-Reset: 1794337597` переводится в **19:06:37 UTC**, раньше recorded capture. Новый Root-пробник также получил Date/reset почти на час раньше capture clock и фактический 403. Причина несогласованности часов/headers здесь не установлена; ожидание по этим цифрам не принималось за восстановление quota. REST-доступ нельзя объявлять восстановленным на основании успешного GitHub web чтения.

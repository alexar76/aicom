# Production x402 integration checks

The ModelMarket apex deployed the fixed GET observer and bridge from `d6a77ce9f` onto the Debian-patched image. The callable manifest and observed seller list retained their prior entries. CoinMarketCap's quotes route returned `200` to HEAD and a 10,000-atom Base USDC offer to GET. The deployed observer accepted the test payment pin and rejected a substituted pin. Public listing requires the seller's consent and a confirmed payment address. Tavily's payment address changed on every probe and is outside the Hub bridge's fixed-recipient policy. [ModelMarket rollout](../hub-x402-observer-2026-11-13/README.md) · [Installed GET probe](../hub-x402-observer-2026-11-13/installed-cmc-probe.json)

The second Hub overlay accepts CoinMarketCap's proprietary receipt only after checking the exact authorized Base USDC transfer. The running Hub verified the existing CMC transaction and refused a modified nonce. The same image kept the publisher withdrawal paid and preserved its one reservation and one paid posting. [Installed CMC proof](../hub-cmc-receipt-2026-11-13/live-cmc-chain.log) · [Publisher ledger check](../hub-cmc-receipt-2026-11-13/post-switch-custody.log)

The first CoinMarketCap pilot submitted one 10,000-atom authorization from the test buyer. The provider returned HTTP 200 and `success=true` without the standard transaction and network fields. A Base RPC lookup found exactly one `AuthorizationUsed` event for the nonce and verified the canonical receipt and matching 10,000-atom USDC `Transfer`. The dedicated owner-only production pilot wallet received 20,000 atoms from the operator's Base wallet. [HTTP result](cmc-http.json) · [Base proof](cmc-chain.json) · [Pilot funding](cmc-pilot-funding.json)

A one-off test used locally signed payment and byte-identical copies of the deployed ARGUS CMC modules. CMC returned HTTP 200 with `success`, `txHash`, `networkId` and `x402FlowId`. The test runner's primary RPC rejected its log lookup due to rate limiting. Independent Base reconciliation found the exact signed nonce, confirmed one 10,000-atom transfer, and verified that 10,000 atoms remained in the dedicated wallet. The final ARGUS rollout replayed both confirmed transfers on Base. It resolved the second directly by its hash and rejected the same hash with a different nonce. Laso rejected $4.99 and returned an exact $5 Base USDC quote. Free wallet sign-in succeeded with a 3,600-second session, and the ARGUS auth helper reused the live token. The merchant API marked the exact `Uber` record `not_accepted`, `Uber Rides` as `unknown` and `Uber Cash` as `accepted`. The adapter declined the `Uber` quote, prepared a quote for the exact `Amazon` merchant record and denied issuance without owner approval. The merchant check does not complete a checkout.

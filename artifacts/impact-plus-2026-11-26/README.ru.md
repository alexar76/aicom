## Точки роста

### 1. Рабочая группа MCP по транспорту пишет «Definition Tags» — и не решила, что входит в метку

Это метка версии списка инструментов в самом протоколе: сервер кладёт `tag` в ответ `tools/list`,
клиент возвращает его при вызове, сервер может отказать, если список устарел.

Что проверено по первичным страницам:

- Черновик — [transports-wg PR #57](https://github.com/modelcontextprotocol/transports-wg/pull/57),
  автор evalstate (Hugging Face). Статус Draft, спонсора нет, авторы «TBD».
- Постановка задачи [#74](https://github.com/modelcontextprotocol/transports-wg/issues/74) принята
  группой 20 ноября («Accept w/ Changes», 3 + 3 голоса). Сравнение охвата
  [#75](https://github.com/modelcontextprotocol/transports-wg/pull/75) открыто, решения нет.
- В черновике метка непрозрачная: клиент сравнивает её только на равенство. Сервер Hugging Face
  добавляет к ней соль. Проверить метку по содержимому списка клиент не может.
- В открытых вопросах черновика прямо стоит: «каноникализация и какие поля определения покрывает
  метка».
- Следующая встреча группы — 4 декабря 16:00 UTC (из заметки от 24.11, сегодня не перепроверял).

Что у нас есть именно к этим вопросам:

- Проба сегодня: 2 000 последних записей об изменениях в HISTOR (07:23–16:03 UTC).
  1 121 из них — один издатель (Pipeworx): за 2 ч 37 мин он добавил четыре инструмента в 1 121 записи
  реестра. Без него остаётся 879 записей на 642 серверах: в 79 % имена те же, изменились только
  определения; в 47 % затронут один инструмент; в 27 % изменилось только описание.
  [Данные](sample-changes.json) · [скрипт](sample_changes.py)
- Уже посчитано раньше: 174 484 чтения, где менялся только счётчик версии внутри инструмента
  (`artifacts/fingerprint-blind-spots-2026-11-19/`). Для метки «на весь список» это сброс кэша на
  каждом чтении.
- `mcp-tool-set-digest/1`: готовый рецепт с 92 векторами и независимыми реализациями — кандидат на
  «один стандартный рецепт», о котором спрашивает черновик.

Почему это крупнее остального: если метка войдёт в протокол, её начнёт отдавать каждый сервер.
HISTOR — единственное место с историей, где можно показать «метка сменилась, а содержимое нет» и
наоборот.

Шаг: один комментарий с данными в PR #57 до 4 декабря. Репозиторий организации MCP — нужна строка
про ИИ, публикует коллега. Правило «данные только туда, где спрашивают» соблюдено: вопрос задан в
самом черновике.

Не проверено: совпадает ли поведение метки на живом сервере Hugging Face с описанием (сервер
требует сессию, я не открывал её).

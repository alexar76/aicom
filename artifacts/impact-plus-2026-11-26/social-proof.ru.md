## Новые точки роста из этого прохода

1. **QuickNode не считает оценку WARDEN.** В формуле репутации (v1.4) учитываются только теги из белого списка: `trust`,
   `quality`, `starred`, `satisfaction`, `helpful`, `reliable`, `reliability`, `responseTime`, `uptime`, `successRate`,
   `liveness`, `efficiency`, `performance`, `job_completion`, `compliance`, `validator_accuracy`. Наш тег `warden-scan`
   показан на странице, но помечен «not in score». Их правило: список пополняется по тегам, которые ставят несколько
   независимых издателей, и один издатель не может давать больше 30 % оценок по тегу. Вариант — публиковать результат под
   тегом из списка, а `warden-scan` оставить вторым тегом. Это решение владельца: подходит ли по смыслу, например, `compliance`.
   Сам файл оценки обозреватель за неделю запросил 66 раз.
2. **Заявка в каталог Docker устарела.** PR docker/mcp-registry#5364 открыт, без конфликтов, но закрепляет коммит
   WARDEN 0.17.0 (в описании PR — 0.8.2), а на npm 0.39.2. Не трогали с 19 октября, комментариев от Docker нет. Последние восемь закрытых заявок там закрыты без
   слияния, так что шанс невелик; обновить версию стоит недорого.
3. **STALA 2027** — срок 11 декабря (подробности в README.ru.md этой папки).
4. **Новый сосед:** zelinsky-alexander/mcp-observatory, платформа долгого наблюдения за MCP-серверами. В наших заметках его не было.
   Прочитал: это ранний прототип на C++ (одна звезда, последний коммит 12 октября), открытых данных и выгрузок у него нет,
   сверять не с чем. Действий не требуется, вернуться, если появятся данные.
   Новая работа arXiv 2611.11104 (набор данных об уязвимостях MCP) — тоже; HISTOR в ней не упомянут.

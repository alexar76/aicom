# Сделать узлом API, который у вас уже работает

[English](run-a-node.md) · [Русский](run-a-node.ru.md) · [Español](run-a-node.es.md) · [Français](run-a-node.fr.md) · [中文](run-a-node.zh.md)

Вы уже что-то продаёте по HTTP — x402-роут, REST-эндпоинт. Чтобы вас находили хабы федерации,
хаб поднимать не нужно: `aimarket node` — небольшой процесс, который стоит рядом с вашим API и
говорит за него на языке протокола.

- Публикует подписанный `/.well-known/ai-market.json` и подписанный манифест названных вами
  роутов; подпись свежая при каждом чтении.
- Отвечает на `POST /ai-market/v2/invoke`, вызывая **ваш** роут — GET с входом в query-параметрах
  или POST с входом в JSON — и пробрасывает заголовки оплаты x402 в обе стороны: ваш 402 доходит
  до покупателя как есть, а оплаченный повтор доходит до вашего роута вместе с оплатой. Работают и
  x402 V1 (предложение в теле), и V2 (предложение в `PAYMENT-REQUIRED`).
- Подписывает квитанцию на каждый ответ 2xx вашего роута.

Деньги остаются там же, где сейчас: узел не держит, не проверяет и не переводит оплату. Ваш роут
делает это, как и сегодня.

## 1. Опишите роуты

```bash
pip install "aimarket-hub[pqc]"            # Python 3.11+, или: uvx --from "aimarket-hub[pqc]" aimarket …
aimarket node init                         # создаст node.toml
```

```toml
name = "Acme weather"
url = "https://api.acme.example"           # где узел видят другие хабы
upstream = "http://127.0.0.1:8000"         # ваш API, как он работает сейчас

[[capability]]
id = "weather.now@v1"
product = "acme-weather"
description = "Current weather for a city"
price_usd = 0.002                          # должна совпадать с тем, что просит 402 вашего роута
method = "GET"
path = "/weather"
input_schema = { type = "object", required = ["city"], properties = { city = { type = "string" } } }
```

Бесплатный роут, если он есть, — самое быстрое доказательство для допуска: песочница вызывает
его и проверяет подпись узла на квитанции. Узел только с платными роутами допускается по его
двери: вызов без оплаты должен ответить 402 с предложением, где названы ваш кошелёк и та же
цена, что в `price_usd`.

## 2. Запустите рядом с API

```bash
aimarket node serve --config node.toml     # → 127.0.0.1:9090 по умолчанию (--host, --port)
```

Направьте на него два пути вашего публичного домена, остальное оставьте как есть. Caddy:

```
api.acme.example {
    handle /.well-known/ai-market.json { reverse_proxy 127.0.0.1:9090 }
    handle /ai-market/* { reverse_proxy 127.0.0.1:9090 }
    handle { reverse_proxy 127.0.0.1:8000 }
}
```

nginx: `location = /.well-known/ai-market.json` и `location /ai-market/`, оба с
`proxy_pass http://127.0.0.1:9090;`. Ключ узла (по умолчанию `data/node_signing_key` и рядом
`_mldsa`) — его личность: сделайте резервную копию.

## 3. Проверьте и постучитесь

```bash
aimarket doctor --url https://api.acme.example   # проверка допуска, которую запустят другие хабы
aimarket node knock                               # анонс на modelmarket.dev (--hub — на другой хаб)
```

В ответе есть `assay_url` — там появится вердикт. При `pass` хабы с автоматическим допуском
индексируют ваши capability: они появляются в их поиске, в их MCP-эндпоинте (`market_search` /
`market_invoke` на `https://modelmarket.dev/mcp`) и на их странице `/hubs`. Покупатель, пришедший
через хаб, видит 402 вашего роута как есть — вместе с заголовком — и платит вам напрямую; хабы не
берут плату за маршрутизацию с прямой x402-продажи (узел объявляет
`payment_rails.seller_direct`, по нему хабы это и узнают).

## Чего узел не делает

- Не назначает цены и не берёт долю — как и хабы, которые проводят к вам прямую x402-продажу:
  то, что покупатель платит вашему роуту, — целиком ваше.
- Не делает ваш роут безопасным или правильным и не ручается за ответ: квитанция, подписанная
  узлом, фиксирует, что роут ответил (capability, цена, время, задержка, успех), а не что он ответил.
- Покупательского трафика в федерации пока мало. Живые счётчики публичны:
  `https://verify.modelmarket.dev/demand.json`.

# Кейс: Codex заказал и оплатил субподряд

[English](case-study-codex-subcontract.md) · [Русский](case-study-codex-subcontract.ru.md) · [Español](case-study-codex-subcontract.es.md) · [Français](case-study-codex-subcontract.fr.md) · [中文](case-study-codex-subcontract.zh.md)

**29 сентября 2026 года** агент, работающий в **Codex**, выполнил реальный заказ на
[modelmarket.dev](https://modelmarket.dev) через `hephaestus / pipeline.run@v1`.
Корневой исполнитель купил две capability GAIA за **0.002 USDC в основной сети Base**
и вернул завершённое дерево SUB/1, подписанный счёт и данные о качестве воздуха в Берлине.
Полная стоимость с комиссией сети составила около **$0.00477** при лимите пользователя $1.

Это интеграционный тест, разрешённый оператором, с предоставленным им кошельком покупателя.
GAIA и Hub относятся к одной управляемой экосистеме; Hub выступал продавцом по расчётам
и получателем платежей. Кейс подтверждает исполнение и оплату реальными средствами,
но не подтверждает спрос независимых клиентов или покупку у независимого владельца.

## Что сделал Codex

Сначала обновление хаба было развёрнуто на проде. Сам заказ затем выполнялся через
**публичный REST API** командами Python и HTTP в терминале Codex, без административных
учётных данных хаба. MCP и браузерный кошелёк для покупки не использовались.

1. Отправил [граф из двух шагов](evidence/codex-subcontract-2026-09-29-blueprint.json)
   в `POST /studio/preflight`, сохранив `source_hub: https://iot.modelmarket.dev`.
2. Вызвал `POST /studio/paid-runs/{run_id}/prepare-pipeline` с адресом покупателя.
3. Проверил баланс, сеть Base **8453**, получателей, суммы и газ относительно бюджета;
   локально подписал авторизации EIP-3009 и транзакции EIP-1559. Закрытый ключ хабу
   не передавался.
4. Отправил `pipeline.run@v1` в `POST /ai-market/v2/invoke`. Исполнитель отправлял каждый
   платёж в сеть непосредственно перед соответствующим дочерним вызовом.
5. Продолжил тот же запуск после HTTP 202, пока ожидались подтверждения. Это повторы
   **одного логического заказа**, а не новые покупки. После перезапуска хаба повторный
   invoke вернул идентичный сохранённый результат, тот же job и хеши транзакций.

```text
Codex → pipeline.run@v1
          ├─ weather: gaia.weather.read@v1 — 0.001 USDC
          └─ air:     gaia.air.read@v1     — 0.001 USDC
```

У обоих детей product ID — `gaia.gateway`. Шаг `air` зависит от завершения `weather`;
оба получают `city: Berlin`. Граф задаёт порядок двух покупок, но не передаёт погоду
на вход анализа воздуха и не проверяет согласованность показаний.

## Результат и стоимость

Оба дочерних вызова завершились успешно. Последний шаг вернул подписанное показание
`om-aq-01`, **GAIA-AQ1 (ретранслятор Open-Meteo AQ)**, на **2026-09-29 20:33:02 UTC**:

| Показатель качества воздуха в Берлине | Значение |
|---|---:|
| PM2.5 | 7.9 мкг/м³ |
| PM10 | 10.1 мкг/м³ |
| US AQI | 41 |
| European AQI | 28 |

Это данные, возвращённые ретранслятором, а не подтверждение наличия отдельного физического
датчика в Берлине. Сохранённый финальный ответ содержит данные о воздухе; успешный шаг
погоды подтверждается квитанцией, но его промежуточное показание в этот ответ не входит.

| Расход | Зафиксированная сумма |
|---|---:|
| Две услуги | 0.002 USDC |
| Комиссии сети, включая публикацию данных в L1 | 0.000001029431613611 ETH |
| Комиссии по записанному курсу ETH/USD | ≈ $0.00276894 |
| Всего | ≈ $0.00476894 |

Для пересчёта использована котировка Coinbase **$2689.775/ETH**, записанная при заказе.
Суммы токенов и комиссии подтверждаются транзакциями; долларовый итог приблизительный.

## Доказательства и границы кейса

- [Публичный пакет доказательств](evidence/codex-subcontract-2026-09-29.json): полный
  подписанный ответ корня, счёт, дерево работ, квитанции сети и публичный ключ хаба,
  записанный до развёртывания.
- Платёж за погоду: [`0x8982…a2285`](https://basescan.org/tx/0x8982b8ac596d0192254017149bc2d1c050c05e838aba7fd5528de7776b0a2285).
- Платёж за воздух: [`0xf974…dc016`](https://basescan.org/tx/0xf974e08b83c1518bed93bfac457f98d7088d3ae6901af9421950d402fb0dc016).
- Запуск: `paid_b78330d3c706ea5bc21424fc06d52603`.
- Job: `job_5d97a26f221d2cec0730e673` — один корень и два ребёнка.

Подписи корня и счёта проверены по ранее записанному ключу хаба, включая хеши счёта
и результата и ссылки на две дочерние квитанции. Подпись показания корректна относительно
вложенного ключа; независимая привязка ключа устройства не проверялась. Обе транзакции
успешны, сумма их комиссий совпала с уменьшением ETH покупателя. В пакете нет закрытого
ключа, токена доступа к запуску и сырых подписанных транзакций.

SUB/1 связывает работы. Источник средств — `buyer_wallet`, у детей — `funded_by: own`.
Кредитная линия, allowance и `X-AIMarket-Job-Grant` не использовались. Отдельно через новый
SKU прошла бесплатная цепочка LOGOS из двух шагов без кошелька. Старому маршруту
`/studio/run` на момент теста ещё требовалась настройка федерации в Factory.

Для нового заказа нужны свежие котировки и авторизации; см.
[пример агента и протокол](../examples/pipeline-run/README.md). Зафиксированные ID —
исторические доказательства, а не платёжные данные для повторного использования.

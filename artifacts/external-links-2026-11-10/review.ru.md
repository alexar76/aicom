# Внешние ссылки на экосистему alexar76 — вечерняя проверка 10 ноября 2026

**Сильнейшая новая связь — содержательный ответ разработчика AgentAvow о совместимости с HISTOR. Дополнительно подтверждены две карточки MCPIndex. Основная масса входящих ссылок по-прежнему приходится на каталоги и копии документации; нового подтверждённого клиента или рабочего внедрения этот проход не установил.**

Первичные чтения выполнены примерно **19:04–19:09 UTC / 20:04–20:09 Europe/Amsterdam**. Основа сравнения — [сегодняшний утренний отчёт](report.ru.md), общий и социально-региональные отчёты 9 ноября. Прежние находки не объявлялись новыми. Существующие отчёты и изменения рабочего кода сохранены.

## Объекты и способ проверки

Текущая satellite-карта содержит 60 записей, в том числе шесть с `github_published: false`, две wiki и профиль. После этих исключений остаётся **51 запись компонента или коллекции с заявленным опубликованным статусом**. Это не 51 независимый продукт. Из поддерживаемых входных страниц извлечено 36 собственных публичных hostname; полная DNS-инвентаризация в задачу не входила. [Инвентаризация с происхождением каждого адреса](baseline/inventory.json).

Выполнены поиск по точным идентификаторам, чтение внешних страниц/публичных API, извлечение буквальных HTML href, сверка с прежними свидетельствами и отдельная проверка адресов назначения. HTML-ссылки, Markdown-ссылки, идентификаторы в тексте, технические ответы, зависимости и совместимые manifests учитываются раздельно. Локализация страницы не определяет страну оператора; внешний аккаунт сам по себе не доказывает независимость владельца.

Собран [единый реестр CSV](reference-register.csv) и его [JSON-версия](reference-register.json). После удаления повторов в нём **337 пар внешняя HTML-страница → наш адрес на 30 внешних страницах**. Дополнительно сохранены ссылки из собственного датасета и другие виды references. Это размер проверенной выборки, не полный backlink index и не прирост с утра. Реестр не пытается включить каждый URL из всех комментариев GitHub: содержательные обсуждения разобраны отдельно в технической ветке.

Плотность ссылок объясняется копированием документации: 274 из 337 HTML-пар приходятся на Odel и LightNow. Десятки ссылок в одном скопированном README не означают десятки независимых рекомендаций. Несколько страниц одного домена также не считаются несколькими операторами.

## Доступность и смысл ссылок

В отдельной воспроизводимой проверке прочитаны **23 внешние страницы**: 22 ответа HTTP 200 и один 403. На 18 страницах с 16 различными доменами найдены прямые HTML-ссылки на наши ресурсы. Четыре доступные страницы — 1gateway, Karatum, Vouch и ответ Linda Dunbar — не содержат такого href в полученном HTML; их содержательные упоминания и наблюдения не превращены в backlinks.

Из найденных адресов отдельно выполнены **125 уникальных GET**:

- **124 ответа HTTP 200**;
- **один HTTP 405** у `https://modelmarket.dev/a2a`: это POST-интерфейс, что соответствует объявленному назначению и локальному `@router.post("/a2a")`. Битой ссылкой он не считается;
- сетевых ошибок, ответов 404/5xx и перенаправлений в этой партии не получено.

Среди проверенных целей — GitHub-репозитории и документы, страницы Hub, Developer Portal, Attested Memory `/docs`, `/start`, `/developers`, `/billing`, Playground и Monitor. Проверка устанавливает HTTP-доступность: 107 больших тел ограничены первыми 120 000 байтами. Заголовки всех страниц и содержимое всех документов целиком не валидировались; якоря разделов, frontend-взаимодействия и выполнение API не проверялись. Из партии исключены маршрут `/x402/x402-check` и SVG-бейдж; они не вызывались.

[Буквальные href, rel и результаты адресов назначения](recheck/backlinks.csv) · [Индекс страниц](recheck/source-index.json) · [Индекс целей](recheck/target-index.json).

У AgentSearch источник данных — `a2aregistry.org`, с сохранённым временем crawl 26 октября. Поэтому его карточка не является вторым независимым испытанием. У Agenstry текущая страница сообщает отсутствие активности за семь дней; старые поисковые snippets не использованы как текущие показатели. Проценты uptime, рейтинги и счётчики чужих площадок не приняты как наша телеметрия или число покупателей.

- **RugSnare:** содержательное переиспользование HISTOR и прямая Markdown-ссылка на version DOI сохраняются; README побайтово совпадает со вчерашним. Новое runtime-внедрение не установлено.

## Неподтверждённое и исключённое

MCPBeat weather остаётся поисковым кандидатом: прямой GET 403. ProtocolProbe weather тоже не прочитан из-за 403. Конкретная карточка MCPWatch HISTOR возвращает 404; это не недоступность самого HISTOR. Ответы 403 и поисковый cache miss не доказывают исчезновения страниц.

AgentAvow ранее просил разрешения поставить ссылку, но в двух проверенных текущих README ссылки на HISTOR ещё нет. PR14 в `agent-skills-state-2026` остаётся open/не merged; собственное предложение не считается внешним принятием. Одноимённые `bracha55555-hue/aimarket` и `sep163/aimarket-agents` снова исключены по проверенным README/requirements: точной связи с нашей экосистемой в этих файлах нет.

Два первоначально предположенных пути в широкой ветке дали 404, после чего прочитаны реальные объявленные пути с HTTP 200. Эти предположения не были внешними href и в список битых опубликованных ссылок не включены. [Полный разбор исключений](ecosystem/summary.md).

## Практический результат

Наиболее обоснованный технический приоритет — закрыть два оставшихся различия профилей HISTOR/AgentAvow воспроизводимыми векторами и продолжать совместимость CrawlCheck. Для учёта внедрений Industrial следует сохранять как историческую связь с недоступным прежним endpoint, а agent-exec — как текущую проверенную совместимость manifest. Увеличение числа каталожных карточек само по себе не доказывает расширения использования.

Новых внешних сообщений или публикаций в этом проходе не отправлялось. Выполнялись публичные чтения и локальная запись свидетельств; без GitHub writes, входа в аккаунты, оплат, invokes и запуска чужого кода. Закрытые обсуждения, приватные репозитории, весь неиндексируемый интернет и полная аналитика трафика не охвачены.

Длины и SHA-256 проверены для всех сохранённых тел: [148 корневых captures](recheck/capture-integrity.json), [31 технического](technical/verification.json) и [30 широкой ветки](ecosystem/capture-integrity.json). Повторяющиеся источники между ветками не складываются в независимые страницы. [Машинная сводка](review-summary.json), [базовая линия и 38 прежних кандидатов](baseline/baseline-summary.md).

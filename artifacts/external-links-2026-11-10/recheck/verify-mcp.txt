market_invoke
~410
Invoke a capability found via market_search. A few trial invokes are granted per caller with no wallet, key or channel, and each returns the hub's signed receipt; when the allowance is spent the hub answers 402 and this reports that rather than inventing a result, with next_steps saying how to pay. Paid access uses the prepaid balance of an API key sent as this connection's X-API-Key header, payment_channel (+ secret), or an on-chain x402 payment (x_payment + x_payment_nonce + x_payment_secret).

What is the AIMarket — live agent marketplace MCP server?

Is the AIMarket — live agent marketplace MCP server safe to use?
AIMarket — live agent marketplace scores 74 out of 100 on VerifyMCP. That is a record of what we were able to check automatically, not an endorsement. The category breakdown on this page shows every signal behind the number, including the ones we could not confirm.
What tools does the AIMarket — live agent marketplace MCP server expose?
AIMarket — live agent marketplace exposes 13 tools: market_search, market_invoke, pipeline_prepare, pipeline_invoke, pipeline_status, and 8 more. Their descriptions and schemas cost roughly 1,807 tokens of context every time the server is loaded.
Does the AIMarket — live agent marketplace MCP server require authentication?
No. We connected to AIMarket — live agent marketplace without credentials and it answered, so anything it exposes is reachable by anyone who knows the address.
Is the AIMarket — live agent marketplace MCP server still maintained?
AIMarket — live agent marketplace is still listed as active in the MCP registry. We last reached this channel on 10 November 2026. Those dates come from our own scans of the registry and the channel itself, not from anything the publisher announced.

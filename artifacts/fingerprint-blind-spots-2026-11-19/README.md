# Что не видит отпечаток инструментов в AI SDK и FastMCP: счёт по срезу HISTOR 2026-11-16

Замер 19.11.2026. Вопрос: сколько записанных HISTOR изменений описаний инструментов MCP остались бы незамеченными,
если сравнивать отпечатки так, как это делают Vercel AI SDK и рецепт из документации FastMCP.

## Данные

Срез HISTOR 2026-11-16 (`https://histor.modelmarket.dev/datasets/2026-11-16/`, CC-BY-4.0), три файла; SHA-256
совпали с подписанным `manifest.json`:

| Файл | SHA-256 |
|---|---|
| `servers.jsonl.gz` | `ab428f72a7b6be1922f5962d2fad2fc0c4251f17b0d54a71c547c3e71a59f924` |
| `changes.jsonl.gz` | `58759f93498c5293b799f52f1e73f7196e33c862c5ddd3e2e861dcfe5a607ecd` |
| `extras_changes.jsonl.gz` | `b724c0e2aae13816553bd51cfd0f132cfe3e61a6bf8b666197408bc500c6cf14` |

Окно: 2026-10-23T18:22:44Z – 2026-11-16T06:29:45Z. Раньше 23.10 HISTOR не хранил аннотации, поэтому раньше считать
нельзя.

## Правила

Прочитаны в исходниках 19.11.2026. На записанных определениях библиотеки не запускались; правило про подсказки
подтверждено одним прогоном настоящей библиотеки на тестовом сервере (раздел «Статья»).

- **AI SDK**: `fingerprintTools` в `ai@7.0.177` (`src/generate-text/tool-fingerprint.ts`) поверх инструментов, которые
  строит `@ai-sdk/mcp@2.0.101` (`src/tool/mcp-client.ts`, режим `automatic`). В отпечаток инструмента входят строка
  `description`, `title ?? annotations.title` и входная схема в виде
  `{...inputSchema, properties: inputSchema.properties ?? {}, additionalProperties: false}`.
  Не входят: `outputSchema`, аннотации кроме `title`, `_meta`, `icons`, `execution`, поля поставщика и верхний
  `inputSchema.additionalProperties`.
- **FastMCP**: базовый набор со страницы «Tool fingerprinting» (New in 3.0.0): ключ инструмента и `inputSchema`.
  Страница прямо говорит, что описание, `outputSchema`, аннотации и `_meta` автор добавляет сам, если нужно.

Одно «чтение» — это один успешный опрос сервера, в котором HISTOR записал изменение (`serverId` + `observedAt`).

Допущения, каждое занижает число «не видно»:

- любое движение `annotations.title` считается видимым для AI SDK;
- чтения с пометкой `truncated` и изменения `names-only` считаются видимыми (2 901 чтение);
- инструмент, добавленный или удалённый в том же чтении, считается видимым.

## Проверка

- На границе среза 02.11 (`…T07:19:57Z`) `blind_spots.py` даёт 201 инструмент на 91 сервере с `readOnlyHint`
  true → false. Это число было получено 10.11 другим расчётом по срезу 2026-11-02.
- `list_hint_flips.py` написан отдельно и идёт от файла аннотаций; его итог совпал с последним столбцом таблицы:
  91 на 32 и 230 на 87.
- Повторный запуск `blind_spots.py` даёт тот же `results-…json` байт в байт.
- Пример прочитан глазами: `https://mcp.altessa.studio/mcp`, чтение 2026-10-25T22:53:04Z — у четырёх инструментов
  `readOnlyHint` и `idempotentHint` сменились с true на false, других изменений в чтении нет.

## Чего этот счёт не говорит

- Смена подсказки — не атака. Большинство таких правок выглядят как исправление неверной аннотации.
- По спецификации MCP аннотации — подсказки, которым клиент не обязан верить. Сколько приложений на AI SDK
  решают по ним, спрашивать ли подтверждение, здесь не измерено.
- HISTOR читает без учётных данных с одного адреса. Серверы с авторизацией и списки, зависящие от пользователя,
  в счёт не входят. Состояния между опросами могут быть пропущены.
- Для пакета «изменение» — это разница между двумя опубликованными версиями, а не смена под тем же адресом.
- Рецепт FastMCP предназначен автору сервера для своих инструментов в CI. Здесь посчитано, что он пропустил бы
  как клиентская проверка, если взять только базовый набор.

## Дополнение 20.11.2026: движения в обратную сторону

Вопрос читателя под статьёй на DEV (Lycore Development, 20.11): переход `readOnlyHint` из true в false стоит считать
жёстким отказом. Обратное направление важно для хостов, которые не спрашивают про инструменты, помеченные «только
чтение»: инструмент, который начал так себя называть, перестаёт вызывать вопрос. `blind_spots.py` теперь считает и его;
прежние строки результата не изменились (проверено сравнением JSON), добавлены новые ключи.

| Движение | Всего | Отпечаток AI SDK не изменился | Из них назад не вернулись | В чтении не изменился ни один отпечаток |
|---|---|---|---|---|
| `readOnlyHint` false → true | 321 инструмент, 78 серверов | 262 инструмента, 30 серверов | 250, 30 серверов | 48 инструментов, 15 серверов |
| `readOnlyHint` нет → true | 38 916, 5 946 | 2 681, 290 | 2 602, 285 | 1 081, 140 |
| `destructiveHint` true → false | 141, 65 | 64, 27 | 64, 27 | 16, 8 |

«Нет → true» в основном — серверы, которые впервые прислали аннотации; это не то же, что смена утверждения.

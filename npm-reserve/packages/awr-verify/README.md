[`@alexar76/awr-verify`](https://www.npmjs.com/package/@alexar76/awr-verify):

```bash
npx -p @alexar76/awr-verify awr-verify verify receipt.json
```

This package verifies nothing; its `awr-verify` command exits 2 and prints the line above.

# Expert Memory Market 사용 사례

Actionable answer가 필요하지만 unlock 전에 authorship, evidence, price를 확인해야
하는 상황에 적합합니다.

## Source-bound research brief

**대상.** Analyst, research team, 전문 미디어.

**업무.** 전체 유료 brief를 공개하지 않고 결론과 방법을 판매합니다. Summary,
`source_refs`, Truth, Provenance를 구매 전에 평가할 수 있습니다.

**권장 경로.** 한 저자에게 지급하면 per-read, collection 탐색이면 pass.

## Incident remediation library

**대상.** SRE, security responder, managed service provider.

**업무.** 검증된 remediation을 machine-readable Memory Unit으로 만듭니다. Agent가
symptom으로 검색하고 contested entry를 제외해 필요한 runbook만 구매합니다.
제공 실패 시 reserve가 해제됩니다.

**권장 경로.** Allowed publisher / Truth policy가 있는 per-read.

## Autonomous agent용 premium context

**대상.** Research, coding, procurement, support agent operator.

**업무.** 전체 corpus를 prompt나 vector store에 복사하지 않고 외부 expertise를
사용합니다. Listing, rank reason, charge, receipt를 최종 output과 저장합니다.

**권장 경로.** Public discovery + spend cap이 있는 per-read.

## Due diligence / compliance intelligence

**대상.** Legal, investment, vendor-risk, compliance team.

**업무.** Claim과 evidence trail을 함께 구매합니다. Listing lineage로 관련성을
판단하고 paid access로 분석을 unlock합니다. 새 evidence가 Truth를 갱신합니다.

**권장 경로.** Active review는 pass, 외부 전문가 의견은 per-read.

## Advisory / implementation playbook

**대상.** Consultant, architect, 전문 agency.

**업무.** Static PDF 대신 context, constraint, failure mode, source, next action을
package해 agent workflow에 직접 연결합니다.

**권장 경로.** Playbook 단위 per-read, 기간 제한 engagement는 pass.

## 평가된 prompt, policy, handoff

**대상.** Agent builder와 AI platform team.

**업무.** Evaluation context가 있는 operating policy를 판매합니다. Provenance는
origin을, Truth는 tested / contested / rejected version을 보여줍니다.

**권장 경로.** Versioned asset per-read와 명시적 cache policy.

## 판매하면 안 되는 것

- Wallet secret, API key, seed phrase, credential.
- 적법한 policy가 없는 personal / regulated data.
- 모호한 summary로 숨긴 unsupported claim.
- 인용한 public source에서 누구나 얻는 commodity document.
- Time-bound entitlement로 표시한 perpetual access.

좁은 category부터 시작하고 [도입 가이드](MARKET_GUIDE.md)를 따르세요.

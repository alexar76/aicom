# Руководство по внедрению Expert Memory Market

Здесь описаны реальные production-контуры для покупателя, издателя и
интегратора агентов. Публичный discovery, платная выдача, учёт доли издателя и
proof — разные контракты. Это разделение сделано намеренно.

## Выберите способ доступа до интеграции

- Trial Expert Market на 1 день проверяет UX и API без транзакции кошелька.
- Expert Pass даёт 7 дней доступа к витрине через scoped-ключ `ask_`.
- Per-read нужен, когда каждая доставленная Memory Unit должна быть отнесена и оплачена конкретному издателю.
- Не смешивайте экономику pass с доходом издателя: pass оплачивает витрину, capture в Meter — долю издателя.

## Проверьте listing до покупки

Вызовите `GET /market/v1/listings?q=<тема>` без ключа. У каждой позиции открыты
summary, `rank_score`, `rank_reasons`, Truth state, Provenance state, цена и
данные издателя. `GET /market/v1/listings/<memory_id>` возвращает одну позицию,
но никогда не раскрывает платное тело.

Отклоняйте позиции, где публичных доказательств недостаточно для вашей
политики. Высокий score — не команда доверять: проверяйте причины. Rejected
claim ранжируется ниже unverified, а популярность не является сигналом.

## Начните с бесплатного trial

Откройте `/` с `trial=expert-market` или используйте мастер настройки. Браузер
создаёт actor identity и оставляет приватный ключ подписи локально. Gateway
выдаёт один trial на 1 день для каждой пары actor/product. Сохраните `ask_` в
secret vault; не помещайте ключ в URL, логи или клиентскую аналитику.

Trial проверяет соответствие продукта задаче. Он не создаёт транзакцию,
publisher split или постоянный entitlement.

## Купите pass или одно доставленное чтение

Для Expert Pass откройте `/billing?plan=expert.pass.7d`, создайте точный инвойс,
отправьте canonical USDC в Base и дождитесь finality от KOVA. Gateway выдаст
ключ продукта на 7 дней. Checkout позволяет восстановить ключ 48 часов —
сохраните его сразу.

Для per-read создайте и пополните аккаунт в Attested Meter, храните `amk_`
только на сервере и вызовите `POST /market/v1/read` с `x-meter-key` и
`{"memory_id":"<id>"}`. Meter резервирует цену до чтения. Capture происходит
только после выдачи платного содержимого; ошибка или отказ освобождают резерв.

## Опубликуйте экспертную memory и назначьте цену

- Создайте полезную Memory Unit: точный title, честный public summary, tags и `source_refs`.
- До включения оплаты добавьте доступные Truth и Provenance evidence.
- Зарегистрируйте издателя через `POST https://meter.attestedmemory.net/v1/publishers` с подписанной actor identity и адресом выплаты в Base.
- Держите publisher key в секрете. Назначайте цену только своей операции через `POST /v1/publishers/me/prices` и `expert.read:<memory_id>`.
- Проверьте listing через публичный `GET /market/v1/listings`, прежде чем приводить покупателей.

Стандартный split успешного чтения — 70% издателю и 30% платформе. Publisher
Pro меняет его на 85% / 15%. После порога оператор выпускает подписанную
`attested.payout/v1` и записывает tx hash выплаты.

## Интегрируйте автономного агента

- Разделите discovery и покупку: агент сначала ищет и оценивает metadata, затем запрашивает разрешение на расход.
- Задайте maximum price, допустимых publishers, Truth states и политику источников.
- Храните `ask_` и `amk_` в server-side secret storage и вырезайте их из traces.
- Трактуйте `401` как неверные credentials, `402` как требование доступа/баланса, `403` как неверный scope, `429` как команду backoff.
- Сохраняйте listing ID, rank reasons, charge ID и provenance receipt рядом с результатом агента.
- Используйте idempotency для инвойсов и не повторяйте перевод с придуманной новой суммой.

## Разверните в команде

- Выберите первую категорию знаний и решение, которое она улучшает.
- Подготовьте 10–20 сильных listings до приглашения покупателей.
- Зафиксируйте минимальный public summary и обязательные source references.
- Проверьте успешный read, неизвестную memory, недостаток баланса, сбой upstream и отзыв ключа.
- Наблюдайте discovery-to-read conversion, refused reads, capture/release, начисления издателей и payout backlog.
- Регулярно пересматривайте старые listings и Truth state; свежесть не должна подменять корректность.

## Понимайте границы доверия и денег

Memory Market ранжирует позиции и выдаёт memory при наличии entitlement.
Attested Meter управляет per-read reserve/capture, учётом издателя и payout-
инструкциями. Attested Prove позволяет проверять receipts и provenance без
передачи API-ключа. KOVA подтверждает точный subscription settlement по
аутентифицированному service-to-service контуру и отдельно доступна через
федерацию.

Ни один компонент не просит seed phrase или приватный ключ кошелька. USDC за
подписку идёт напрямую получателю; выплаты издателям — подписанные и записанные
инструкции, исполняемые отдельно. См. [KOVA_CAPABILITIES.md](KOVA_CAPABILITIES.md)
и [MARKET_USE_CASES.md](MARKET_USE_CASES.md).

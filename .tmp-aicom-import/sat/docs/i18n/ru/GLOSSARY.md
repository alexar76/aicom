# Короткий словарик

| Термин | Простое объяснение |
|---|---|
| API key | Секретный ключ доступа к оплаченному продукту. |
| Actor identity | Подписанная идентичность, от имени которой выполняется запрос. |
| Public/private key | Public key проверяет подпись; private key создаёт её и остаётся у вас. |
| Memory Unit | Одна сохранённая единица знаний. |
| Provenance | История происхождения и изменений памяти. |
| Invoice | Точная инструкция по оплате до отправки USDC. |
| Tx hash | Идентификатор blockchain-транзакции; сам по себе он ещё не доказывает оплату. |
| Confirmation | Число блоков, подтверждающих включение транзакции. |
| Entitlement | Ограниченное по времени право пользоваться тарифом. |
| Namespace | Граница, отделяющая записи одной команды от другой. |
| Rate limit | Временное ограничение числа запросов. |
| Trial | Короткий бесплатный доступ, привязанный к actor и автоматически истекающий. |

# Expert Memory Market ユースケース

Actionable answer が必要で、unlock 前に authorship、evidence、price を確認する
場面に適しています。

## Source-bound research brief

**対象。** Analyst、research team、専門メディア。

**仕事。** 完全な有料 brief を公開せず、結論と手法を販売します。Summary、
`source_refs`、Truth、Provenance を購入前に評価できます。

**推奨。** 1件の author を支払うなら per-read、collection 探索なら pass。

## Incident remediation library

**対象。** SRE、security responder、managed service provider。

**仕事。** 検証済み remediation を machine-readable Memory Unit にします。
Agent は symptom で検索し contested entry を除外して必要な runbook だけ購入。
配信失敗時は reserve が解放されます。

**推奨。** Allowed publisher / Truth policy 付き per-read。

## Autonomous agent 向け premium context

**対象。** Research、coding、procurement、support agent の operator。

**仕事。** Corpus 全体を prompt や vector store にコピーせず外部 expertise を利用。
Listing、rank reason、charge、receipt を最終 output と保存します。

**推奨。** Public discovery + spend cap 付き per-read。

## Due diligence / compliance intelligence

**対象。** Legal、investment、vendor-risk、compliance team。

**仕事。** Claim と evidence trail を一緒に購入。Listing の lineage で関連性を
判断し、paid access で詳細分析を unlock。新しい evidence は Truth を更新します。

**推奨。** Active review は pass、外部専門家の意見は per-read。

## Advisory / implementation playbook

**対象。** Consultant、architect、専門 agency。

**仕事。** Static PDF ではなく context、constraint、failure mode、source、next
action を package。Buyer は provenance 確認後 agent workflow に直接接続できます。

**推奨。** Playbook 単位は per-read、期間限定 engagement は pass。

## 評価済み prompt、policy、handoff

**対象。** Agent builder と AI platform team。

**仕事。** Evaluation context 付き operating policy を販売。Provenance は origin、
Truth は tested / contested / rejected version を示します。

**推奨。** Versioned asset の per-read と明示的 cache policy。

## 販売してはいけないもの

- Wallet secret、API key、seed phrase、credential。
- 適法な policy のない personal / regulated data。
- 曖昧な summary で隠した unsupported claim。
- 引用した public source から誰でも取得できる commodity document。
- Time-bound entitlement と表示した perpetual access。

# Casos de uso de Expert Memory Market

El mercado encaja cuando el comprador necesita una respuesta accionable, pero
debe revisar autoría, evidencia y precio antes de desbloquearla.

## Informe de investigación ligado a fuentes

**Quién.** Analistas, equipos de research y publicaciones especializadas.

**Trabajo.** Vender conclusión y método sin regalar el informe completo. El
resumen público, `source_refs`, Truth y Provenance permiten evaluarlo primero.

**Mejor vía.** Pago por lectura para remunerar un informe; pass para explorar
una colección.

## Biblioteca de remediación de incidentes

**Quién.** SRE, respuesta de seguridad y proveedores gestionados.

**Trabajo.** Convertir pasos probados en Memory Units legibles por máquina. Un
agente busca por síntoma, descarta entradas contestadas y compra el runbook
preciso. Si la entrega falla, la reserva se libera.

**Mejor vía.** Pago por lectura con publishers y Truth states permitidos.

## Contexto premium para agentes autónomos

**Quién.** Operadores de agentes de research, código, compras y soporte.

**Trabajo.** Usar experiencia externa sin copiar el corpus entero a prompt o
vector store. Guardar listing, motivos, charge y provenance receipt con la salida.

**Mejor vía.** Descubrimiento público y autorización por lectura con límite.

## Due diligence e inteligencia de compliance

**Quién.** Legal, inversión, vendor-risk y compliance.

**Trabajo.** Comprar el claim con su rastro de evidencia. El listing muestra
linaje suficiente; el acceso pagado abre el análisis. Nueva evidencia actualiza
Truth y el ranking futuro.

**Mejor vía.** Pass para una revisión activa; per-read para opinión externa.

## Playbooks de consultoría e implementación

**Quién.** Consultores, arquitectos y agencias especialistas.

**Trabajo.** Empaquetar contexto, límites, fallos, fuentes y siguiente acción en
lugar de un PDF estático. El resultado entra directamente en un workflow.

**Mejor vía.** Per-read por playbook; pass para un proyecto limitado.

## Prompts, políticas y handoffs evaluados

**Quién.** Builders de agentes y plataformas de IA.

**Trabajo.** Vender una política probada con evaluation context. Provenance
muestra origen y Truth distingue versiones tested, contested y rejected.

**Mejor vía.** Per-read para assets versionados y cache policy explícita.

## Qué no vender aquí

- Wallet secrets, API keys, seed phrases o credenciales.
- Datos personales o regulados sin política legal.
- Claims sin soporte ocultos por un resumen vago.
- Documentos básicos disponibles en la fuente pública citada.
- Acceso perpetuo presentado como entitlement temporal.

Empieza con una categoría estrecha y sigue la [guía de implementación](MARKET_GUIDE.md).

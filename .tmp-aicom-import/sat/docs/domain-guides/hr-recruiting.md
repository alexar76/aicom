# HR / Recruiting (ATS) — playbook

> **Built-in pack:** `hr_recruiting` — see [README.md](./README.md) and [methodology-agent.md](../methodology-agent.md).

- Pipeline is **opening → application → screen → interview → offer → hire/reject** with audit trail.
- **Stage reasons** and **disposition** on reject/withdraw to measure funnel quality.
- Scheduling and **scorecards** should attach to the candidate record, not only email.
- Offer and PII: restrict visibility by role; export controls for compliance.
- Funnel metrics: **time to hire**, **conversion by stage**, **offer acceptance**.

# Ecommerce Best Practices

> **Built-in pack:** `ecommerce` — see [domain-guides/README.md](./README.md) and [methodology-agent.md](../methodology-agent.md).

- Make checkout resilient: preserve cart state and recover from payment interruptions.
- Keep inventory updates atomic around order placement.
- Track funnel metrics by step: view, add-to-cart, checkout-start, purchase.
- Prioritize performance on listing/product pages; optimize above-the-fold content.
- Support robust refund and order-status workflows with clear customer communication.
- Prevent promo abuse with rate limits and per-user coupon constraints.

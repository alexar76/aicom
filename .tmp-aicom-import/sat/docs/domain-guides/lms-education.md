# LMS / Education — playbook

> **Built-in pack:** `lms_education` — see [README.md](./README.md) and [methodology-agent.md](../methodology-agent.md).

- Separate **catalog browse**, **enrollment**, **lesson consumption**, and **assessment** flows.
- Track **completion** per lesson/module with durable progress (not only client state).
- Quizzes need **attempt limits**, **review of wrong answers** where appropriate, and **integrity** basics.
- Certificates or completion badges should tie to **passed assessments**, not page views.
- Authoring vs learner roles: protect course structure and grades from learner accounts.

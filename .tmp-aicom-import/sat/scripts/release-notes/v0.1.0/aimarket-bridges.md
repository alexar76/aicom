# aimarket-bridges v0.1.0

First public satellite release: AIMarket capabilities as native tools for LangChain/LangGraph, CrewAI, and AutoGen.

## Highlights
- Shared core + three framework adapters (`langchain`, `crewai`, `autogen`)
- Budget caps, free-trial path, signed receipts verified against the **origin** key
- Refusals return readable tool text instead of crashing the agent graph

Relay Scout — ecosystem health watchdog

Monitors alexar76 endpoints: AI-Factory, Alien Monitor, DIOSCURI, and AIMarket hub. YAML-driven scheduled polling, JSON snapshot diff, webhook digest alerts, and a devtools ops API for deployments, logs, and alert acknowledgement.

For: DevOps / SRE teams operating alexar76 microservices.

Endpoint health polling

HTTP checks on a YAML-driven schedule for factory, monitor, and dioscuri targets.

JSON snapshot diff

Store snapshots and detect config drift between polls — added, removed, and changed fields.

Webhook digest alerts

Deduplicated downtime and drift notifications to Slack, Teams, or PagerDuty.

CLI & YAML configuration

relay-scout check|diff|watch with YAML targets list.

Devtools ops API

Projects, deployments (queued → running → succeeded/failed/rolled back), logs, alert ack lifecycle.

Ops API lifecycle

Poll ecosystem health endpoints, persist snapshots, compute diffs, acknowledge incidents.

CLI & YAML configuration

relay-scout check --config relay-scout.yaml
relay-scout diff factory --config relay-scout.yaml
relay-scout watch --config relay-scout.yaml --once
targets:
  - name: factory
    url: https://magic-ai-factory.com/api/health
  - name: monitor
    url: https://monitor.modelmarket.dev/api/health

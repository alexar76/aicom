第一版在测试数据上正常运行。但在还没有客户时，收入计算出错。经过内部修复尝试，缺陷仍然存在。这时可以请专家协助。

01

AICOM 构建

工厂将需求转化为计划和代码。测试发现空数据会触发故障。

02

AIMarket 连接

AICOM 在预算范围内向获批专家购买诊断服务，仅分享允许提供的代码和故障信息。

03

专家诊断

报告指出除零错误，建议处理客户列表为空的情况，并提供代码引用。

04

AICOM 验证并继续

工厂验证报告，将其用于下一次修复尝试，再运行原有测试。只有通过检查，才能继续交付。

一个产品，一项明确的外部贡献。工厂仍然负责构建工作。

获批服务商 · 支出上限 · 仅分享许可代码 · 保留原有测试。

哪些部分已验证？

生产诊断集成已通过使用 Hub 额度和签名报告的付费测试。测试采用人为构造的除零缺陷，服务商由同一运营方拥有。已验证的是采购与报告接收，并非完整的产品修复流程。

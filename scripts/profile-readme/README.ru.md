```bash
pip install aimarket-mcp
```

```json
{ "mcpServers": { "aimarket-mcp": { "command": "aimarket-mcp" } } }
```

Оракулы для агентов (35 инструментов): [`aimarket-oracle-gateway`](https://github.com/alexar76/aimarket-oracle-gateway) · [Glama](https://glama.ai/mcp/servers/alexar76/aimarket-mcp)

**Три строки → подписанный результат Hub** (нужен бюджет на [modelmarket.dev](https://modelmarket.dev)):

```python
from aimarket_agent import AIMarketAgent
r = AIMarketAgent(base_url="https://modelmarket.dev", budget=1.0).invoke_single(
    "platon", "platon.random@v1", {"nbytes": 32})
print(r.get("receipt") or r)  # подписанная квитанция оракула
```

Сначала выполните `pip install aimarket-agent`.

**LangGraph / CrewAI / AutoGen** (нативные инструменты из возможностей Hub):

```python
from aimarket_bridges.langchain import aimarket_tools
tools = aimarket_tools("https://modelmarket.dev", intent="verifiable randomness")
```

`pip install "aimarket-bridges[langgraph]"` · [руководство](https://modeldev.modelmarket.dev/guides/aimarket-bridges/) · [репозиторий](https://github.com/alexar76/aimarket-bridges)

После Playground разверните тот же путь поставщика локально:

```bash
uvx create-aimarket-agent my-agent --kind data-provider --metis
```

[Исходный код Playground](https://github.com/alexar76/aimarket-playground) · [исходный код CLI](https://github.com/alexar76/create-aimarket-agent)

### Запустите всё целиком

Одна команда поднимает всю экономику на VPS или ноутбуке: Factory, Hub, Service Mesh, семейство
оракулов, Metis, LOGOS, GAIA, ATLAS, ARGUS, MOMUS + Treasury, SKOPOS, DIOSCURI, HELIOS — и открывает
Alien Monitor с пульсирующим живым графом.

```bash
git clone https://github.com/alexar76/aicom && cd aicom && ./start.sh --everything
```

Система сама генерирует все секреты, выводит их **один раз**, ждёт реального ответа каждого сервиса
на health check и только после этого открывает монитор. Если что-то не запустилось, она сообщает,
какой именно компонент, и останавливается, а не открывает страницу с ложным статусом.

Доступ по адресу `http://<your-ip>:<port>` — без nginx, TLS и доменов. По умолчанию привязка
только к localhost; `--bind 0.0.0.0` открывает внешний доступ и точно указывает открываемые порты плоскости управления.

```bash
./start.sh                 # core only: Factory + Hub + Mesh + Monitor — a laptop tier
./start.sh --everything    # the full fleet, ~40 containers
./start.sh --down          # stop, keep the data
```

**Чего команда не делает:** не развёртывает контракты в реальной цепочке (для этого намеренно
предусмотрен отдельный скрипт) и не тратит реальные деньги — криптовалюта отключена, а встроенная
цепочка получает тестовые средства и существует временно.
Полная инструкция: [docs/deploy-everything.md](https://github.com/alexar76/aicom/blob/main/docs/deploy-everything.md) · двухминутный обзор: [YouTube](https://youtu.be/Gg9a52-ZbNA)

Я создаю рельсы для экономики, в которой **автономные AI-агенты** обнаруживают друг друга, заключают сделки и получают оплату: от Factory, производящей продукты, до маркетплейса, где они размещаются, и рынка капитала, который определяет их стоимость.

Всё ниже — **единая связанная система**, а не набор отдельных репозиториев.

### Как всё связано

Один конвейер в том порядке, в котором действительно движутся доверие и деньги. На каждом этапе указаны выполняющие его репозитории.

| # | Этап | Кто выполняет |
| --- | --- | --- |
| 1 | **Сборка** | [`aicom`](https://github.com/alexar76/aicom) проектирует, собирает, тестирует и публикует продукты |
| 2 | **Допуск** | **THEMIS** принимает решение во время публикации — подписанные `approve` / `review` / `reject` |
| 3 | **Размещение и вызов (invoke)** | [Протокол](https://github.com/alexar76/aimarket-protocol) **AIMarket** + [Hub](https://github.com/alexar76/aimarket-hub) передают каталог, каналы и вызовы |
| 4 | **Поставка** | 17 **оракулов** (случайность, задержка, консенсус, математика доверия) · аттестованные физические показания **GAIA** · когнитивный слой **METIS** |
| 5 | **Верификация** | когнитивный слой **METIS** · Solidity в закреплённом коммите от **BASANOS** · живые EVM-эксплойты от **DOLOS** · HTTP/федерация от **MOMUS** · сторонний MCP от **WARDEN** |
| 6 | **Потребление** | **ARGUS** — клиент на стороне спроса, который действительно запускают люди и агенты |
| 7 | **Расчёт** | эскроу, платёжные каналы и вознаграждения **Treasury**, выплачиваемые только после независимой верификации |
| 8 | **Финансирование** | **ACEX** оценивает агентов, размещает их и выдаёт займы под них |
| 9 | **Наблюдение** | **SKOPOS** наблюдает за флотом · **LOGOS** — за федерацией · **Alien Monitor** показывает всё в живом 3D |

Ниже каждый репозиторий находится **ровно в одной** группе — соответствующей его роли в конвейере. Если
вам известно только название, перейдите к [указателю A–Z](#az).

### 🛡 Доверие и безопасность — кто получает допуск и кто платит за найденное
<sub>Этап 5 и рельсы вознаграждений.

# Variables scripts/redeploy_in_place.sh must NOT carry into a rebuilt Alien Monitor.
#
# Both monitor containers were created by a bare `docker run` whose environment came from
# `env_file: ../.env` — the entire monorepo .env. That line is gone from
# alien-monitor/docker-compose.prod.yml, but nothing rebuilds these containers from compose:
# the redeploy script captures the environment the running container already has, so
# without this list the inherited variables would survive every future rebuild.
#
# Measured on 2026-09-11 against the running `alien-monitor` by diffing its environment
# against EVERY uppercase literal in alien-monitor/backend/*.py: the names below appear
# nowhere in the monitor's source. It reads its LLM keys through the provider config's
# `api_key_env`, so DEEPSEEK_API_KEY and OPENROUTER_API_KEY are deliberately NOT here.
#
# One name per line; `#` comments and blanks ignored. A name in
# /root/.<container>.extra.env still wins — that file is an operator saying "yes, really".

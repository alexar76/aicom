# SKOPOS v0.1.0

First public release of **SKOPOS (Σκοπός)** — self-hosted nginx analytics and fleet security for the AICOM ecosystem.

## Highlights

- **Analytics** — nginx/apache log ingestion over SSH, traffic globe, premium themes
- **Security Center** — 3D threat map, posture audit, fail2ban, TLS checks, AI remediation report
- **Scan History** — score timeline, trends, comparison
- **AI agent** — sidebar assistant with voice input (OpenRouter)
- **Quick Start wizard** — guided fleet setup
- **i18n** — 15+ locales, localized docs on GitHub Pages

## Install

```bash
docker pull ghcr.io/alexar76/skopos:v0.1.0
# or
pip install skopos-fleet==0.1.0
```

Docs: https://alexar76.github.io/skopos/

## AIMarket SDKs v0.1.0 (early)

**What works today**
- TypeScript (`@aimarket/agent`), Dart (`aimarket_agent`), Rust (`aimarket_agent`) at **0.1.0**
- Hub v2 discovery, channel open, invoke helpers
- TEE attestation verification helpers (where enabled)

**Unstable / may change**
- API surface and error types across languages may diverge until 1.0
- Default hub URLs and timeout defaults

**Not in this release**
- Published packages on npm/pub.dev/crates.io (source-only; registry publish is a later step)

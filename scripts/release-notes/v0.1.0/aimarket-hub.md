## AIMarket Hub v0.1.0 (early)

**What works today**
- FastAPI hub: manifest, search, channels, invoke, plugin loader
- Payment channel flows and federation hooks (testnet-oriented)
- Plugin ecosystem (safety, reputation, TEE, etc.) in-tree

**Unstable / may change**
- Plugin ABI, database schema, and admin routes
- Production hardening and rate limits

**Not in this release**
- PyPI publish (disabled until `PYPI_API_TOKEN` and package name are finalized)
- Mainnet financial guarantees

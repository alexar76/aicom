## AIMarket Protocol v0.1.0 (early)

**What works today**
- v2 spec draft, JSON schemas (`well-known`, `manifest`, `receipt`, federation)
- Signed test vectors for manifest, receipt, federation announce
- Ecosystem map and integration examples

**Unstable / may change**
- Field names and weights in reputation scoring
- Federation wire format before wider adoption
- `hub_version` coupling — treat as documentation, not a frozen ABI

**Not in this release**
- Formal RFC status, third-party certification, or semver guarantees on wire compat beyond 0.x policy

# WARDEN 0.39.2 — Canari attestation adapter in the npm package

```bash
npm install -g @aimarket/warden@0.39.2
```

Ships the Canari attestation verifier (PR #15, lanbass869-cell) so JavaScript and TypeScript
consumers can import it from `@aimarket/warden/canari`. The adapter verifies a signed
attestation against the caller's artifact digest and public key.

The full text is in the [CHANGELOG](https://github.com/alexar76/warden/blob/v0.39.2/CHANGELOG.md).

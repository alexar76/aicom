# Project / Task management — playbook

> **Built-in pack:** `project_management` — see [README.md](./README.md) and [methodology-agent.md](../methodology-agent.md).

- Tasks need **assignee**, **status**, and **due** semantics that work in filters and boards.
- **Comments** and **attachments** should stay on the task for traceability.
- Avoid infinite “in progress” — define **blocked** / **review** states and transitions.
- Reporting: **throughput**, **cycle time**, **WIP** — not only a pretty Kanban.
- Permissions: project membership vs global admin for cross-team safety.

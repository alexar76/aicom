# Helpdesk / IT support — playbook

> **Built-in pack:** `helpdesk_support` — see [README.md](./README.md) and [methodology-agent.md](../methodology-agent.md).

- Tickets need **priority**, **assignee**, and **SLA timers** that survive reopens.
- Threaded **public vs internal** comments; customers must not see internal-only notes by mistake.
- **Escalation** paths and breach visibility (queue health, not only per-ticket view).
- **CSAT** or outcome capture after resolution, with optional re-open flow.
- Search/filter across status, assignee, and tags — a static FAQ page is not a helpdesk.

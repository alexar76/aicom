# Healthcare Best Practices

> **Built-in pack:** `healthcare_wellness` — see [domain-guides/README.md](./README.md) and [methodology-agent.md](../methodology-agent.md).

- Default to privacy-by-design: collect minimum PHI and mask logs.
- Separate identifiers from medical content when possible.
- Add explicit consent and data-retention controls per workflow.
- Use role-based access control with audit logs for every record view/update.
- Validate clinical inputs with strict schema and unit normalization.
- Keep incident runbooks for data exposure and downtime scenarios.

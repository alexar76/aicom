**Demo en vivo:** [magic-ai-factory.com](https://magic-ai-factory.com) ·
**Monitor UNI:** [monitor.modelmarket.dev](https://monitor.modelmarket.dev/) ·
**Monitor LIVE:** [monitor.modelmarket.dev](https://monitor.modelmarket.dev/) ·
**Playground:** [play.modelmarket.dev](https://play.modelmarket.dev/)

AI-Factory convierte un prompt en un producto web listo para publicar — pipeline multiagente
(research → design → code → QA → deploy) con escaparate, **rails** de pago y observabilidad en vivo.
Las claves y los datos se quedan en tu infra (**autoalojado**).

## Demo en 30 segundos

MCP alojado: `https://modelmarket.dev/mcp` — herramientas `market_search` / `market_invoke` contra el **Hub** vivo, con **recibo** firmado. Invocaciones de prueba gratis; luego **402** y ruta de **depósito en garantía (escrow)**.

Contratos en Base **MAINNET** (demo): [onchain-journal.md](onchain-journal.md).

## Inicio rápido

```bash
git clone https://github.com/alexar76/aicom && cd aicom && ./start.sh --everything
```

# Glossário rápido

| Termo | Explicação simples |
|---|---|
| API key | Chave secreta para acessar o produto pago. |
| Actor identity | Identidade assinada que faz a requisição. |
| Public/private key | A pública verifica; a privada assina e deve ficar com você. |
| Memory Unit | Uma unidade de conhecimento salva. |
| Provenance | Histórico da origem e das mudanças da memória. |
| Invoice | Instrução exata de pagamento antes de enviar USDC. |
| Tx hash | Identificador da transação; sozinho não prova o pagamento. |
| Confirmation | Número de blocos que confirma a inclusão da transação. |
| Entitlement | Direito temporário de usar um plano pago. |
| Namespace | Limite que separa os registros de cada equipe. |
| Rate limit | Limite temporário de requisições. |
| Trial | Acesso gratuito curto, vinculado a um actor e com expiração automática. |

# Casos de uso

## Segundo cérebro pessoal

Salve uma decisão com justificativa, fontes e tags. Antes de reutilizá-la,
confira truth status e provenance.

## Memória operacional de equipe

Use um namespace para incidentes, runbooks e decisões. A membership é validada
no Gateway e as consultas não atravessam outra equipe.

## Mercado de conhecimento especialista

Um especialista publica uma Memory Unit paga com fontes. O comprador vê o resumo,
paga a invoice exata na Base e recebe acesso por tempo limitado.

## Handoff entre agentes

Um agente assina contexto, limites e fontes. O próximo verifica provenance em vez
de confiar em um resumo não assinado.

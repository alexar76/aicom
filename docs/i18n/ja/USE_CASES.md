# ユースケース

## 個人のセカンドブレイン

判断の理由、出典、タグと一緒に保存し、再利用する前に truth status と provenance を確認します。

## チームの運用知識

インシデント、runbook、判断をチーム namespace に保存します。Gateway が membership を確認し、
Hub の検索は別チームへ越境しません。

## エキスパート市場

専門家が出典付きの有料 Memory Unit を公開します。購入者は summary を確認し、Base の正確な
USDC invoice を支払って、期限付きの読み取り権限を得ます。

## エージェント間の引き継ぎ

エージェントが context、制約、出典を署名します。次のエージェントは署名なしの要約ではなく provenance を検証します。

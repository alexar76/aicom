# 用語ミニ辞典

| 用語 | 簡単な説明 |
|---|---|
| API key | 有料プロダクトへのアクセスに使う秘密のキー。 |
| Actor identity | リクエストを行う署名付き identity。 |
| Public/private key | public は署名を検証し、private は署名を作成して自分だけが保持する。 |
| Memory Unit | 保存された1つの知識。 |
| Provenance | memory の出典と変更履歴。 |
| Invoice | USDC を送る前に作成される正確な支払い指示。 |
| Tx hash | transaction の識別子。これだけでは支払いの確定ではない。 |
| Confirmation | transaction が含まれた block の確認数。 |
| Entitlement | 有料プランを使う期限付きの権利。 |
| Namespace | チームのデータを分離する境界。 |
| Rate limit | 一時的なリクエスト数の上限。 |
| Trial | actor に紐づき、自動的に終了する短期間の無料利用。 |

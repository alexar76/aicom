# 핵심 용어

| 용어 | 쉬운 설명 |
|---|---|
| API key | 유료 제품에 접근하는 비밀 키입니다. |
| Actor identity | 요청을 보내는 서명된 identity입니다. |
| Public/private key | public은 서명을 확인하고 private은 서명을 만들며 사용자만 보관합니다. |
| Memory Unit | 저장된 하나의 지식 단위입니다. |
| Provenance | memory의 출처와 변경 기록입니다. |
| Invoice | USDC를 보내기 전에 만드는 정확한 결제 지시입니다. |
| Tx hash | transaction 식별자이며 이것만으로 결제가 확정되지는 않습니다. |
| Confirmation | transaction 포함을 확인하는 block 수입니다. |
| Entitlement | 유료 플랜을 사용할 수 있는 기간 한정 권리입니다. |
| Namespace | 팀별 기록을 분리하는 경계입니다. |
| Rate limit | 일시적인 요청 수 제한입니다. |
| Trial | actor에 연결되고 자동으로 만료되는 짧은 무료 이용 기간입니다. |

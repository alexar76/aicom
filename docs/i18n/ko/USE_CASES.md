# 사용 사례

## 개인 세컨드 브레인

결정의 이유, 출처, 태그를 함께 저장하고 재사용 전에 truth status와 provenance를 확인합니다.

## 팀 운영 지식

장애 기록, runbook, 결정을 팀 namespace에 저장합니다. Gateway가 membership을 확인하고 Hub 검색은 다른 팀으로 넘어가지 않습니다.

## 전문가 마켓

전문가가 출처가 있는 유료 Memory Unit을 공개합니다. 구매자는 summary를 확인하고 Base의 정확한 USDC invoice를 결제한 뒤 기간 한정 접근을 받습니다.

## 에이전트 인수인계

에이전트가 context, 제한사항, 출처를 서명합니다. 다음 에이전트는 서명 없는 요약이 아니라 provenance를 검증합니다.

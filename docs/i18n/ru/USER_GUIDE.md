# Полевое руководство

## Оплатите один раз. Сохраните ключ.

На `/billing` выберите Personal, Team или Market. Checkout фиксирует точную
сумму USDC, получателя, токен, сеть и срок. Отправьте эту сумму в Base,
дождитесь подтверждений и вставьте tx hash.

Платный ключ `ask_...` можно восстановить по секрету checkout 48 часов; затем
хранится только хеш. Держите ключ в менеджере паролей. Gateway сверяет оплату
даже если браузер закрыт. Ротация — `POST /v1/keys/rotate`, отзыв —
`POST /v1/keys/revoke`, проверка — `GET /v1/keys/me`.

## Докажите, кто действует. Запишите, что остаётся.

В продуктах передавайте ключ в `X-SaaS-Key` — это не подпись actor.

Для защищённых вызовов нужны `X-Actor-ID`, `X-Actor-Public-Key` и
`X-Actor-Signature`. Приватный ключ остаётся в браузере или runtime агента.
Запись — `/memory/api/memories`, поиск — `/memory/api/search`. Личные private
чтения требуют того же actor, которому принадлежит память.

## Команда без общих секретов.

Создайте команду через `/teams/api/teams`, добавьте участников через
`/teams/api/teams/{team_id}/members` и указывайте `team_id` в каждом запросе.
Gateway проверяет membership; Hub — короткоживущий team assertion и подпись.

`401` — неверный ключ или proof. `403` — неверный scope. `402` — нужна оплата.
`429` — rate limit. Никогда не отправляйте приватные ключи в API.

## Начните бесплатно. Перейдите чисто.

Trial через `/v1/trials`: Personal — 7 дней, Team — 14, Expert Market — 1.
Gateway выдаёт привязанный к actor `ask_...` без оплаты; тот же подписанный
actor может восстановить его, пока trial активен. Срок истекает сам — дальше
точная оплата USDC в Base. См. [TRIAL.md](TRIAL.md).

## KOVA отдельно. Checkout точно.

Агенты находят KOVA через федерацию Hub. Checkout Attested идёт по защищённому
service-to-service маршруту, поэтому потребление capability не запускает
рекурсивную оплату. Оба пути, квитанции и границы — в
[KOVA_CAPABILITIES.md](KOVA_CAPABILITIES.md).

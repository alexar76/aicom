# Бесплатный trial и переход на оплату

Для Personal доступен бесплатный trial на 7 дней, для Team — на 14 дней, для
Expert Market — на 1 день. Один actor может активировать trial один раз для
каждого продукта.

Браузер создаёт Ed25519 actor proof. Gateway выдаёт одноразовый `ask_...`-ключ
без оплаты кошельком. Ключ автоматически истекает и использует те же правила
introspection, rotation и revoke, что и платный ключ.

При переходе на платный тариф Gateway создаёт точный invoice в canonical USDC
на Base. KOVA проверяет транзакцию, а после нужного числа подтверждений новый
платный ключ выдаётся автоматически.

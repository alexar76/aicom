# Сценарии использования

## Личная база знаний

Сохраняйте решение вместе с обоснованием, ссылками и тегами. При повторном
поиске проверяйте truth status и provenance перед использованием.

## Память инженерной команды

Создайте team namespace для incident notes, runbooks и решений. Membership
проверяется gateway, а запросы Hub не пересекают границу другой команды.

## Рынок экспертных знаний

Эксперт публикует платную Memory Unit с источниками. Покупатель видит summary,
оплачивает точный Base-инвойс и получает ограниченное по времени право чтения.

## Передача контекста агенту

Агент подписывает handoff с контекстом, ограничениями и источниками. Следующий
агент проверяет provenance, а не доверяет неподписанному пересказу.

# Casos de uso

## Segundo cerebro personal

Guarda una decisión con su razonamiento, fuentes y etiquetas. Antes de reutilizarla,
comprueba truth status y provenance.

## Memoria operativa de un equipo

Usa un namespace para incidentes, runbooks y decisiones. La membresía se valida
en Gateway y las consultas no pueden cruzar a otro equipo.

## Mercado de conocimiento experto

Un experto publica una Memory Unit de pago con fuentes. El comprador descubre el
resumen, paga el invoice exacto en Base y obtiene acceso temporal.

## Handoff entre agentes

Un agente firma contexto, límites y fuentes. El siguiente agente verifica la
provenance en lugar de aceptar un resumen sin firma.

# Glosario breve

| Término | Explicación sencilla |
|---|---|
| API key | Clave secreta para acceder al producto pagado. |
| Actor identity | Identidad firmada que realiza la solicitud. |
| Public/private key | La pública verifica; la privada firma y debe permanecer contigo. |
| Memory Unit | Una unidad guardada de conocimiento. |
| Provenance | Historial del origen y cambios de una memoria. |
| Invoice | Instrucción exacta de pago antes de enviar USDC. |
| Tx hash | Identificador de la transacción; por sí solo no demuestra el pago. |
| Confirmation | Número de bloques que confirma la inclusión de la transacción. |
| Entitlement | Derecho temporal a usar un plan pagado. |
| Namespace | Frontera que separa los registros de cada equipo. |
| Rate limit | Límite temporal de solicitudes. |
| Trial | Acceso gratuito breve, vinculado a un actor y con caducidad automática. |

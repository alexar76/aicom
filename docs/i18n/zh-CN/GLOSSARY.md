# 快速术语表

| 术语 | 简单解释 |
|---|---|
| API key | 访问付费产品的秘密密钥。 |
| Actor identity | 发起请求的签名 identity。 |
| Public/private key | public 用于验证签名，private 用于生成签名并必须由你保管。 |
| Memory Unit | 一条保存的知识。 |
| Provenance | memory 的来源与变化记录。 |
| Invoice | 发送 USDC 前生成的精确付款指令。 |
| Tx hash | transaction 标识；单独存在不能证明付款已完成。 |
| Confirmation | 用于确认 transaction 被写入区块的数量。 |
| Entitlement | 使用付费套餐的限时权利。 |
| Namespace | 隔离不同团队记录的边界。 |
| Rate limit | 临时请求数量上限。 |
| Trial | 绑定 actor、会自动到期的短期免费使用权。 |

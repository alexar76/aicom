# 使用场景

## 个人第二大脑

把决策、理由、来源和标签一起保存，在复用前检查 truth status 与 provenance。

## 团队运营知识

在团队 namespace 中保存事故记录、runbook 和决策。Gateway 检查 membership，Hub 查询不会跨越团队边界。

## 专家知识市场

专家发布带来源的付费 Memory Unit。买家先查看摘要，再支付 Base 上精确的 USDC invoice，获得限时读取权限。

## 智能体交接

智能体对 context、限制条件和来源进行签名。下一个智能体验证 provenance，而不是相信未签名的聊天摘要。

# Kullanım senaryoları

## Kişisel ikinci beyin

Bir kararı gerekçesi, kaynakları ve etiketleriyle saklayın; kullanmadan önce truth status ve provenance'ı kontrol edin.

## Ekip operasyon hafızası

Olayları, runbook'ları ve kararları ekip namespace'inde tutun. Gateway membership'i doğrular, Hub sorguları başka ekibe geçmez.

## Uzman bilgi pazarı

Uzman kaynaklı ücretli bir Memory Unit yayınlar. Alıcı özeti görür, Base üzerindeki tam USDC invoice'ı öder ve süreli erişim alır.

## Ajan handoff'u

Bir ajan context'i, kısıtları ve kaynakları imzalar. Sonraki ajan imzasız özete güvenmek yerine provenance'ı doğrular.

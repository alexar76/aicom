# Kısa sözlük

| Terim | Basit açıklama |
|---|---|
| API key | Ücretli ürüne erişim sağlayan gizli anahtar. |
| Actor identity | İsteği yapan imzalı identity. |
| Public/private key | Public imzayı doğrular; private imzayı üretir ve sizde kalır. |
| Memory Unit | Kaydedilmiş tek bir bilgi birimi. |
| Provenance | Memory'nin kaynağı ve değişiklik geçmişi. |
| Invoice | USDC göndermeden önce oluşturulan kesin ödeme talimatı. |
| Tx hash | Transaction kimliği; tek başına ödeme kanıtı değildir. |
| Confirmation | Transaction'ın block'a yazıldığını doğrulayan sayı. |
| Entitlement | Ücretli planı kullanma süresi sınırlı hakkı. |
| Namespace | Ekip kayıtlarını birbirinden ayıran sınır. |
| Rate limit | Geçici istek sayısı sınırı. |
| Trial | Actor'a bağlı, otomatik sona eren kısa ücretsiz kullanım süresi. |

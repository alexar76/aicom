# Anwendungsfälle

## Persönliches zweites Gehirn

Eine Entscheidung mit Begründung, Quellen und Tags speichern und vor der späteren
Nutzung Truth Status und Provenance prüfen.

## Team-Betriebswissen

Ein Namespace für Incidents, Runbooks und Entscheidungen. Gateway prüft die
Mitgliedschaft; Hub-Anfragen können keinen anderen Team-Namespace lesen.

## Expertenmarkt

Ein Experte veröffentlicht eine kostenpflichtige, quellenbasierte Memory Unit.
Der Käufer bezahlt die exakte Base-USDC-Rechnung und erhält zeitlich begrenzten Zugriff.

## Agenten-Handoff

Ein Agent signiert Kontext, Grenzen und Quellen. Der nächste Agent prüft die
Provenance statt einer unsignierten Chat-Zusammenfassung zu vertrauen.

# Kurzes Glossar

| Begriff | Einfache Erklärung |
|---|---|
| API key | Geheimer Schlüssel für den bezahlten Produktzugang. |
| Actor identity | Signierte Identität, die eine Anfrage stellt. |
| Public/private key | Der öffentliche Schlüssel prüft; der private signiert und bleibt bei Ihnen. |
| Memory Unit | Eine gespeicherte Wissenseinheit. |
| Provenance | Herkunfts- und Änderungshistorie einer Memory. |
| Invoice | Exakte Zahlungsanweisung vor dem USDC-Versand. |
| Tx hash | Transaktionskennung; allein kein Zahlungsnachweis. |
| Confirmation | Anzahl der Blöcke, die die Aufnahme bestätigt. |
| Entitlement | Zeitlich begrenztes Nutzungsrecht für einen Plan. |
| Namespace | Grenze zwischen den Datensätzen verschiedener Teams. |
| Rate limit | Zeitweise Begrenzung der Anfragezahl. |
| Trial | Kurzer kostenloser, an eine Actor-Identität gebundener Zugang mit Ablauf. |

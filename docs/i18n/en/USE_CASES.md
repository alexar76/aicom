# Use cases

## Personal second brain

Capture a decision with its rationale, source links and tags. Later, search the
catalog and verify the attached truth and provenance state before relying on it.

## Team operating memory

Create a team namespace for an engineering group. Members write incident
notes, runbooks and decisions. Membership is checked by the gateway and Hub
queries cannot cross into another team namespace.

## Expert knowledge market

An expert publishes a source-linked paid Memory Unit. A buyer searches public
summaries, pays the exact Base USDC invoice, then reads the unit through a
time-bound entitlement.

## Agent handoff

An agent writes a signed handoff containing context, constraints and source
references. A second agent can retrieve it and inspect provenance rather than
trusting an unsigned chat summary.

# Quick glossary

| Term | In simple words |
|---|---|
| API key | A secret pass for your paid product access. |
| Actor identity | The signed identity that makes a memory request. |
| Public/private key | Public data verifies a signature; private data creates it and must stay with you. |
| Memory Unit | One saved piece of knowledge. |
| Provenance | The record of where a memory came from and what happened to it. |
| Invoice | The exact payment instruction created before you send USDC. |
| Tx hash | The blockchain transaction identifier; it is not proof until verified. |
| Confirmation | A block inclusion count used to reduce reorg risk. |
| Entitlement | The time-bound right to use a paid plan. |
| Namespace | A boundary that keeps one team’s records separate. |
| Rate limit | A temporary request cap that protects the service. |
| Trial | A short free, actor-bound entitlement that expires automatically. |

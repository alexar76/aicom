# Petit glossaire

| Terme | Explication simple |
|---|---|
| API key | Clé secrète donnant accès au produit payé. |
| Actor identity | Identité signée qui effectue la requête. |
| Public/private key | La publique vérifie ; la privée signe et reste avec vous. |
| Memory Unit | Une unité de connaissance enregistrée. |
| Provenance | Historique de l’origine et des changements de la mémoire. |
| Invoice | Instruction exacte avant l’envoi d’USDC. |
| Tx hash | Identifiant de transaction ; seul, il ne prouve pas le paiement. |
| Confirmation | Nombre de blocs confirmant l’inclusion. |
| Entitlement | Droit temporaire d’utiliser une offre payée. |
| Namespace | Frontière séparant les données des équipes. |
| Rate limit | Limite temporaire du nombre de requêtes. |
| Trial | Accès gratuit court, lié à un actor et expirant automatiquement. |

# Cas d’usage

## Seconde mémoire personnelle

Conserver une décision avec sa raison, ses sources et ses tags, puis vérifier la
truth status et la provenance avant de la réutiliser.

## Mémoire opérationnelle d’équipe

Utiliser un namespace pour les incidents, runbooks et décisions. La membership
est vérifiée par le Gateway et les requêtes ne traversent pas une autre équipe.

## Marché d’expertise

Un expert publie une Memory Unit payante et sourcée. L’acheteur découvre le résumé,
paie la facture USDC exacte sur Base et obtient un accès limité dans le temps.

## Passage entre agents

Un agent signe le contexte, les limites et les sources. Le suivant vérifie la
provenance plutôt que de faire confiance à un résumé non signé.

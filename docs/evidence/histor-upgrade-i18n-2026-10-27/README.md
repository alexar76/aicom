# Проверка языков отчёта HISTOR

Это свидетельство предыдущего состояния с русским языком по умолчанию. Позднее по явному
указанию пользователя default изменён на английский; актуальная
[проверка default и пяти языков на реальных данных](../histor-real-upgrade-i18n-2026-10-27/README.md)
фиксирует новое поведение. Приведённые ниже результаты относятся к прежней проверке.

Дата: 27 октября 2026 года. Все изменения и проверки выполнены локально в `aicom`.

`histor upgrade-brief` принимает `--lang ru|en|es|fr|zh`. Прежние вызовы без флага используют
русский язык. Python API принимает `build_report(path, lang="en")`; поле `language` сохраняется
в JSON, а `markdown(report)` читает его и поддерживает старые отчёты без этого поля.

Переводятся встроенные заголовки, пояснения, чеклисты инструментов и сценариев, границы анализа
и запасной заголовок. Значения статусов и диагностических причин JSON, схемы, хеши, исходные
цитаты и пользовательские названия сохраняются. Известные диагностические причины получают
локализованные пояснения в Markdown. Экранование пользовательских данных сохранено.

Прошли 99 связанных тестов разбора, снятия снимков с подставным reader, рендеринга и локализации,
включая 38 новых регрессионных тестов. Проверены все пять языков в JSON и Markdown, русский
по умолчанию, старый отчёт без `language`, отказ неизвестному языку до чтения файлов или
создания результатов, неизменность технических данных и экранирование HTML, Markdown,
управляющих символов и bidi. Дополнительные случаи покрывают неизвестные extras, добавленный
или отсутствующий инструмент, неполные метаданные и неизменившийся сценарий.

Пример дважды запущен для каждого языка в Python 3.12.13 без site-packages (`-S -B`): всего
10 запусков. Проверены конкретный перевод заголовка и чеклиста в Markdown и JSON, одинаковые
результаты анализа, побайтовая повторяемость каждого языкового отчёта и неизменность входов.
Сводка для всех языков: `changed: 1`, `unchanged: 0`, `context_changed: 1`, `unknown: 1`.

У всех 70 сообщений каталога есть пять переводов с одинаковыми placeholders. В десяти
руководствах и описаниях примера проверены 90 локальных ссылок и 10 JSON-блоков; все прошли
проверку. Сценарии описывают перепроверки для отдельного стенда: сам пример не запускает
MCP-серверы и не вызывает инструменты. `capture`, установка пакетов, сетевые запросы,
деплой и публикации в GitHub не выполнялись.

Повторить проверку всех языков из каталога `histor/` с Python 3.11 или новее:

```bash
python3 examples/upgrade-brief/verify.py \
  --out-dir ../output/histor-upgrade-brief-example
```

Повторный запуск заменяет сгенерированные отчёты в языковых папках. Исходные снимки общие для
всех языков; для своих названий и описаний сценариев выбирайте соответствующий watchlist.

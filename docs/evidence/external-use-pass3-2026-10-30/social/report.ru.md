[query-index.json](query-index.json) содержит все запросы с отметкой повторов; полные ответы — search-0.json…search-9.json. [http-index.json](http-index.json) фиксирует два новых прямых GET и SHA-256 тел. Web-open сохранён отдельно; его cache miss для feed затем закрыт успешным обычным GET.

Выполнялись только публичные чтения и локальная запись свидетельств; сообщений, публикаций, авторизаций, покупок и GitHub writes в этой ветке не было.

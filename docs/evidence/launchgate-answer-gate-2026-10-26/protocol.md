# Host-owned structured answer boundary — frozen implementation verification

26 October 2026. No publication. Runtime source changes stay local; use Linux factory-vps for build/tests. No model calls in the first verification stage.

## Contract

Opt-in host integration owns normalized rules, all captured records, session/turn, model generation callback and final output sink. It buffers the proposal before display. The structured model answer has only schema, exact catalog digest, selected record reference and complete eligible-reference set. Model-authored prose/prices/extra metadata are not a verified supported surface.

Every referenced item is checked against every rule after every proposal. The complete eligible set and optional min/max ranking are verified. A valid selected ID cannot excuse false alternatives. Source facts remain conditional on the trusted host snapshot; no server truth verification or effect permission is granted. Safe record aliases and field handles replace arbitrary source names/IDs/labels in model catalogs and feedback.

The host runs an initial proposal and at most two corrections (one bounded extra pass beyond the old one-correction design). C-to-D substitution must produce fresh D distance counterevidence, then either pass all constraints or be withheld. Unknown/malformed/stale/incomplete data never allows final delivery. Provider/timeout/cancel failures are not automatically retried. One gate instance reserves one output, and uncertain sink completion is never resent.

Host notice emission is independent of model prose and included in the actual stdio host example's output. This proves only the included integration boundary/stdio output, not third-party native-client GUI rendering. Ordinary Stop hooks retain their one-continuation behavior; no infinite hook loop or universal prose validator is claimed.

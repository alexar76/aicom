# Живая проверка MCP и A2A — 31 октября 2026

[Полный отчёт и матрица проверок на английском](README.md)

На `modelmarket.dev` выполнены три реальных платежа по **0.001 USDC в Base**: исходный тест A2A, повторная проверка исправленного A2A и отдельная проверка MCP. Проверены перевод, получатель, сумма и использование nonce счёта. Ed25519-подпись квитанции валидна по ключу поставщика; подмена цены и подстановка ключа хаба отклоняются. Общий расход с комиссиями — около **$0.00637264** по записанным курсам ETH.

Первый оплаченный Task выявил сбой: квитанция была подписана, но результат A2A оказался `null`. Исправление потери `output` выложено на хаб. После него пример A2A и MCP вернули погодные данные и валидные квитанции. Сначала исправления были проверены **подаренными сервисными кредитами**, затем — двумя отдельно разрешёнными реальными переводами USDC. Исправленный A2A-пример завершился с кодом `0`; повтор команды выполнил только чтение. MCP выдал данные и квитанцию, а повтор использованного платежа отклонил. Исторический оплаченный Task сохраняет исходный `null`; его квитанция после исправления SDK верифицируется.

Также исправлены выбор ключа поставщика при продолжении x402, ложный успех примера без данных и восстановление команды запуска, порта и прав общего реестра платежей в скрипте деплоя. Первая выкладка была прервана и откачена; исправленная выкладка прошла проверку. Исходный контейнер оставлен для отката, окружение, тома, порты и сети сохранены.

Прошли **491 автоматический тест**, ещё 2 пропущены. Живые проверки подтвердили поиск, данные, квитанции, ограничение цены, отклонение неверных параметров, версии и ключа, а также повтор A2A с тем же `messageId` без нового списания. Повтор исходного оплаченного x402-запроса вернул тот же Task без нового перевода.

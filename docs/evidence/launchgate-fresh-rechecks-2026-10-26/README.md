## Custody and interpretation

The API key stays on factory-vps, outside the no-network guard/test container and all collected evidence. Model calls go only through the prior tested host relay. Exact requests, responses, full answers and usage are retained for the scored repeat. No retries, fallback model, booking, payment, GitHub writes, npm/blog/article publication or comment posting.

Treatment labels are omitted from the deduplicated text-review index. This does not make the same agent's AI-assisted review independent or blinded adjudication. Review every complete unique answer, encode factual assertions and exact disclosure spans, and retain uncertainty. A correct selected ID alone cannot establish factual correction. Guard notice emission is separate from model-prose disclosure and native rendering. Repetitions of four known errors across two fixture families do not establish generalization.

# Evidence-reference × correction-request experiment — 26 October 2026

Execution and complete-text review finished. [Frozen protocol](protocol.md), [collection discipline](custody.md).

12 exact saved initial contexts × 8 repetitions × 4 treatments = 384 fresh model continuations. Two factors: ordinal versus explicit record/field evidence; conditional review versus direct correction of mechanically confirmed contradictions. Primary correction opportunities: four known erroneous explanations × eight = 32 per treatment. Eight supported contexts are byte-identical message controls across all four treatments. This is known-case research, not an independent holdout.

The explicit treatment uses validated synthetic IDs and fixed fact templates. It never inserts arbitrary source-authored names, descriptions or instruction quotes into the warning. The direct treatment replaces only the repeat-if-correct sentence in flagged contexts. These are research-adapter transformations; no WARDEN runtime change is part of this study.

Instrument tests, actual compiled-hook preparation and fixed-runtime final replay run on factory-vps in a nonroot, read-only-root, no-network container. The existing host-local relay alone calls the model; credentials never enter payload, container or evidence. All raw requests/responses, complete answers and usage are retained. No retry, booking/payment/tool effect, GitHub/npm/blog/article/comment write.

The repaired collector retains server data on download/verification failure. Cleanup occurs only after local archive and member hashes match. `--recover` performs read-only collection followed by verified cleanup and never dispatches model calls. Local supervisor logs and remote-root receipts are preserved. The cap for this new experiment is $0.12 conservative accounting, up to 384 calls; rates are accounting assumptions, not a verified current-tariff invoice.

Before the first paid dispatch, the server saves exact input hashes, four treatment messages, predictions/protocol hash, custody hash and randomized schedule. No outcome-driven prompt, grammar, sample-size or runtime tuning is permitted. Compare the four fresh conditions directly rather than treating the earlier 19/32 as this experiment's control.

Post-hoc AI-assisted text review will cover all complete unique answers. Previously reviewed labels may be reused only for exact fixture/answer matches; every new full text is read and annotated with exact quote/hash-bound claims. Independent human/blinded adjudication is not claimed. Model-prose disclosure, guard notice emission and native-client rendering stay separate.

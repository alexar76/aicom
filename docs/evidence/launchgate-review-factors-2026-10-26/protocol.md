## Design

Same twelve saved initial answers and exact original four-message conversations as the previous retained 288-continuation study. Four contain false eligibility/price explanations, eight have supported annotated selection claims. All selected IDs are admissible. Generate eight fresh continuations per context and treatment: **12 × 8 × 4 = 384 calls**. The primary correction denominator is 4 × 8 = 32 per treatment. No fresh initial answers are generated.

Factor A: original ordinal evidence versus explicit controlled record/field/consequence evidence. Explicit form identifies the synthetic record (e.g. T-4-C), its captured nightly price 190, user cap 150 and ineligibility under that price constraint. This is a record-and-field presentation bundle, not a pure character-level ID ablation; do not attribute all gains specifically to reference resolution. Only fixed, validated synthetic IDs are allowed, never arbitrary server-authored names, descriptions or quoted instructions.

Factor B: existing conditional permission to repeat the answer if correct versus direct correction of a mechanically confirmed contradiction. The direct treatment replaces only the existing repeat-if-correct sentence with a fixed correction directive; all other review text stays unchanged. It does not ask the model to adjudicate whether the checked contradiction is real. The selected ID may remain unchanged if admissible, and source-instruction disclosure must be preserved.

Treatment labels: `ordinal_conditional`, `explicit_conditional`, `ordinal_directive`, `explicit_directive`. For the eight cases without a detected contradiction neither factor changes the review: all four messages are byte-identical baseline review controls. This avoids inventing errors to correct. The current compiled candidate's numeric-evidence Stop output is the fresh `ordinal_conditional` baseline; keep exact previous study baseline-message equality checks. Message changes are research-adapter transformations, not released runtime changes.

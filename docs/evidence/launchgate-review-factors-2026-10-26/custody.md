# Collection discipline carried forward

This is a new factorial experiment, not a retry of the earlier study. The prior study's first execution lost its evidence after a failed SSH collection; its declared operational repeat retained all data. Those historical attempts remain separate and are not pooled here.

Reuse only the repaired collector: remote root persisted immediately, server-side archive SHA-256, local archive and member verification before cleanup. On any failure retain remote evidence and recover without model calls. Five collection regressions must pass before any paid call. All new calls, outcome failures and accounting are retained. There is no silent repeated model run after data loss.

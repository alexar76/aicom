MCP transparency log chce zaznamenávat skutečné rozhraní veřejných MCP serverů

MCP transparency log sleduje veřejné MCP servery a ukládá historii jejich nástrojů do append only záznamu s ověřitelnými hlavami.

Radyz 5. 10. 2026 · Zdroj: GitHub ↗

MCP transparency log je nezávislý projekt, který chce průběžně zaznamenávat, jaké nástroje veřejné MCP servery skutečně nabízely. Autor zdůrazňuje rozdíl mezi podpisem vydavatele a pozorováním třetí stranou: podpis potvrdí, kdo novou podobu publikoval, ale sám neukáže, že se popis nástroje od posledního auditu změnil. Crawler podle dokumentace navštěvuje veřejně dosažitelné servery z oficiálního registru, ukládá názvy, popisy, JSON schémata a anotace nástrojů do append only logu se signed tree heads. Projekt uvádí raný stav, dokončený crawler, archiv pozorování, denní census a Merkle log podle RFC 6962. Pro ekosystém MCP může být důležitá právě dlouhodobá historie změn, ne jednorázový sken.

# Проверка входа в экосистему — 11 октября 2026

## Итог и статус публикации

Живой путь до первого результата работает: лендинг фабрики → гостевой генератор → готовая страница → ZIP. Переходы к экосистеме, рынку и обучению работают, но сквозной путь знакомства требует более явной навигации и точного объяснения возможностей публичного демо.

Все изменения этого прохода оставлены локально. Пользователь выбрал «Пока оставить локально» после просмотра предложения обновить 67 публичных файлов в 17 репозиториях. Массовая публикация перед этим была отклонена автоматической проверкой из-за широты охвата. Записей в GitHub, обновлений npm и production-деплоев в этом проходе не было.

Позднее пользователь уточнил место публикации: Gitea, через `scripts/push_gitea_monorepo.sh`. Подготовленные исходники, документация и доказательства входят в коммит монорепозитория для Gitea; публикация в GitHub и production-деплой этим запросом не выполняются.

## Что пока мешает погружению

- **Разрыв обещания и режима доступа.** Большая история обещает создание продуктов, но публичный быстрый результат — лендинг. Полную сборку следует представлять как следующий самостоятельный шаг с развёртыванием или отдельным согласованным заказом, а не как доступную каждому кнопку в публичной админке. Пояснение подготовлено локально.
- **Два разных гостевых генератора.** На главной — постановка в конвейер с QA; отдельный Instant Lab делает страницу непосредственно. Разница недостаточно очевидна. В этом тесте от начала до ZIP проверен Instant Lab, а не полный конвейер главной страницы.
- **Карточки в доработке воспринимаются как готовые примеры.** У проверенного продукта доступны превью и покупка, но также видны Human Review и провал последнего QA. Для первого знакомства нужен отобранный набор действительно готовых примеров; статусы и QA нельзя скрывать. Состояния продуктов в этом проходе не менялись.
- **Язык и техническая нагрузка.** В русской фабрике часть фильтров/FAQ/карточек остаётся английской; Instant Lab тоже англоязычный, хотя генерирует русский результат. На первом экране и карточках много операторских терминов и деталей стека.
- **Старый GitHub Pages вход.** `alexar76.github.io` всё ещё отправляет на `modeldev.modelmarket.dev`; отдельно согласованные README этого не меняют. Для согласованного публичного входа нужен будущий перевод этого редиректа на `ecosystem.modelmarket.dev` либо публикация подготовленного атласа. По выбору пользователя GitHub оставлен без изменений.

Рекомендуемый сквозной путь: понять, что создаёт фабрика → получить маленький результат → увидеть роль фабрики в атласе → пройти один короткий пример обмена → выбрать собственную роль (покупатель услуги, разработчик/поставщик, оператор фабрики).

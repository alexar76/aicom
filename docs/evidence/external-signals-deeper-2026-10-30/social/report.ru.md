# Углублённая проверка социальных сигналов alexar76 30 октября 2026 года

**Новой независимой текстовой публикации или реального использования продуктов в этом проходе не подтверждено.** Закрыт конкретный пробел прежнего аудита: доступна родная публичная лента Bluesky и ветки собственных публикаций, хотя поисковый endpoint ранее возвращал 403. Найден один атрибутируемый репост другим аккаунтом, обозначенным как bot; он учитывается как автоматическое распространение.

База сравнения включает не только отчёт 30 октября, но и оба машинных аудита 29 октября. Поэтому QuincyGB, его предложение Verdict Row и статья 25 октября не названы новыми находками.

## Прямое чтение Bluesky

Обычный [getAuthorFeed](https://public.api.bsky.app/xrpc/app.bsky.feed.getAuthorFeed?actor=alexar76.bsky.social&limit=100) вернул HTTP 200, **58 записей**, без cursor следующей страницы. Все записи принадлежат alexar76.bsky.social; даты — с 5 июля по 27 октября. Это состав полученной ленты, без утверждения, что API гарантирует включение удалённых или скрытых записей.

Для всех 19 записей с ненулевым replyCount прочитаны getPostThread, depth 10. В полученных деревьях — **38 вхождений собственных постов, 37 уникальных URI, ноль внешних текстовых ответов**. Счётчик replyCount сам по себе не был признаком чужого обсуждения: видимые продолжения написаны самим alexar76.

Для четырёх записей с ненулевым repostCount прочитаны getRepostedBy. У трёх списки пусты; участники им не приписывались. Четвёртый список возвращает **timxai.ai**, DID did:plc:wc247qet6fmuzynmhehrsfdl, для [поста об AI factory и marketplace](https://bsky.app/profile/alexar76.bsky.social/post/3mpv2cab2vk2r) от **5 июля 10:25 МСК**. В ответе есть self-label bot и описание AI company.

Это подтверждает распространение поста аккаунтом с другим DID. Человеческий отзыв, независимость владельца, применение AICOM или нашего API не установлены. **Дата самого репоста API не предоставлена**; indexedAt профиля не использован вместо неё. В просмотренных прежних docs/artifacts timxai не найден; оригинальный пост и его закрепление уже были известны. Следовательно новая здесь — атрибуция репоста, а не июльский анонс или новый сегодняшний отклик.

Ни Bluesky search API, ни его 403 в этом проходе не повторялись. Публичная лента и getPostThread — другие штатные читающие endpoint, доступные без авторизации. Полного поиска чужих постов по всему Bluesky это не заменяет.

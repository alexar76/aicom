## Ограничения

- Основной источник итальянских и американских сведений — официальная WIPO Global Brand
  Database. Она предупреждает о возможной неполноте и задержках данных; национальную
  актуальность итальянских статусов отдельно подтвердить не удалось.
- Прямой USPTO TSDR вернул HTTP 429; API требует ключ (401).
- UKIPO вернул 403, Роспатент — 502. Полнота поиска РФ, Великобритании и ЕС не установлена.
- Поиск ЭМПОРИОН в WIPO показал тот же набор результатов с латинскими обозначениями;
  это не отдельная проверка отсутствия кириллических знаков в российских реестрах.
- Поиск похожих написаний и незарегистрированных обозначений не исчерпывающий.
  Отсутствие записи в доступной выдаче не означает отсутствие прав третьих лиц.

## Значение слова

Древнегреческое **ἐμπόριον** — торговая станция, торговое место, рынок или центр торговли.
Источник: [Liddell–Scott–Jones, ἐμπόριον](https://atlas.perseus.tufts.edu/dictionaries/entry/urn%3Acite2%3Ascaife-viewer%3Adictionaries.v1%3Alsj-n34491/).
Это историческое торговое слово; его словарное происхождение само по себе не определяет
доступность современного товарного знака для конкретных товаров, услуг и территорий.

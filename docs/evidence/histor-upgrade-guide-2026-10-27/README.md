# Проверка руководства и примера HISTOR

Это свидетельство проверки предыдущего состояния, где встроенный текст отчётов был русским.
Позже добавлен выбор языка; актуальная [проверка локализации](../histor-upgrade-i18n-2026-10-27/README.md)
содержит результаты пяти языковых отчётов. Хеши ниже фиксируют состояние на момент прежней проверки.

Дата: 27 октября 2026 года. Материалы подготовлены и проверены локально в `aicom`.

Подготовлены пять руководств и пять пошаговых описаний примера: английский, русский,
испанский, французский и упрощённый китайский. Пять watchlist переводят только заголовки и
описания сценариев, сохраняя общие шесть синтетических наблюдений, ID и выбранные инструменты.
Служебный текст автоматически создаваемых отчётов остаётся русским; это указано во всех версиях.

- [Руководство](https://github.com/alexar76/histor/blob/main/docs/upgrade-brief.ru.md) с навигацией по пяти языкам.
- [Воспроизводимый пример](https://github.com/alexar76/histor/blob/main/examples/upgrade-brief/README.ru.md).
- [Ожидания](https://github.com/alexar76/histor/blob/main/examples/upgrade-brief/expected.json) и
  [скрипт проверки](https://github.com/alexar76/histor/blob/main/examples/upgrade-brief/verify.py).
- [Сводка проверки и SHA-256 файлов](verification.json).
- [Лог десяти офлайн-запусков](example-verification.log).
- [Ruff](ruff.log) и [проверка пробелов в diff](diff-check.log).

Все проверки прошли. В Python 3.12.13 без site-packages (`-S -B`) проверочный скрипт дважды
запустил CLI для каждого языка: сверены ожидаемые изменения входной и выходной схем,
annotations, удаление выбранного инструмента, статусы четырёх сценариев, побайтовая
повторяемость отчётов, одинаковый анализ между языками и неизменность входов. Дополнительно
проверены 90 локальных ссылок и 10 JSON-блоков в десяти документах; JSON принят валидаторами
текущего прототипа.

Сводка каждой языковой версии: `changed: 1`, `unchanged: 0`, `context_changed: 1`, `unknown: 1`.
Отчёты находятся в `output/histor-upgrade-brief-example/{en,ru,es,fr,zh}/` от корня workspace.
Скрипт сверяет определения и отчёты; описанные пользовательские сценарии требуют отдельного
стенда и не исполнялись как MCP-вызовы. Команды `capture` и установки пакетов из руководства
не запускались. Сетевых запросов, деплоя и публикаций в GitHub не было.

Повторить из каталога `histor/` с Python 3.11 или новее:

```bash
python3 examples/upgrade-brief/verify.py \
  --out-dir ../output/histor-upgrade-brief-example
```

При необходимости замените `python3` на `.venv/bin/python`. Повторный запуск заменяет только
сгенерированные отчёты в выбранных языковых папках. Для других входных данных нужно отдельно
задать ожидаемые результаты; этот набор фиксирует синтетический пример.

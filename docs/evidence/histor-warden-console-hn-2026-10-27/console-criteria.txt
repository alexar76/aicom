<main id="main-content" tabindex="-1" class="shell about-page"><h1>console.dev Selection Criteria</h1>
<p>Console is the place to discover the best tools and beta releases for developers. We&#39;re always trying out new tools - whether brand new releases, updates, or things we&#39;ve rediscovered - but we only feature the most interesting. This page explains our selection criteria for how we choose.</p>
<section><h2>Interesting tools</h2>
<p>Each week we feature and review 2-3 interesting developer tools in the Console newsletter and on our website.</p>
<p>Our selection criteria are explained below. The more of these questions we can answer positively, the more likely a tool is to be featured. We try to be objective but there is always a subjective element to deciding what we think is the best, most interesting set of tools each week:</p>
<ul>
<li><p>Is this interesting and useful to developers?</p>
</li>
<li><p>Is the primary user a developer? A developer might use it, but is it built specifically with developers in mind?</p>
</li>
<li><p>Is there a self-service signup? A demo or speaking to sales may be an option, but an individual developer should be able to try it themselves without speaking to anyone.</p>
</li>
<li><p>Would this form part of a regular-use set of developer tools? Does it fit into the development cycle? Is it a part of the development flow?</p>
</li>
<li><p>Does it make me a better developer? Does it help me reduce/manage bugs, improve build times, get code to production faster, reduce/manage errors, etc?</p>
</li>
<li><p>Would this be used by advanced power-users? Does it support dark mode, is there an API and/or CLI, are there keyboard shortcuts, what about accessibility?</p>
</li>
<li><p>Is the tool high quality? Does it work on multiple platforms and/or browsers? Is it easy to install/deploy? Does it do the job it claims?</p>
</li>
<li><p>Is it being actively maintained with regular bug fixes and updates?</p>
</li>
<li><p>Does it have good documentation?</p>
</li>
<li><p>Is it fast?</p>
</li>
<li><p>Does it have any negative impact on security or privacy?</p>
</li>
<li><p>How would I feel recommending this to my friends? Would I share a link to it?</p>
</li>
</ul>
</section><section><h2>Betas</h2>
<p>We only list early access, alpha, or beta releases of tools where developers are the primary user.</p>
<p>To determine whether something falls under this definition, we use Semver version numbers i.e. the release must be pre 1.0 and/or have an appropriate label in the version number e.g. 1.0.0-beta. Alternatively, the word &quot;beta&quot;, &quot;preview&quot; or similar should appear somewhere easily discoverable on the website, release notes, and/or documentation. Any GA or stable releases are not eligible.</p>
</section><section><h2>Sponsors</h2>
<p>Console works with <a href="/advertise">advertisers</a> who want to reach our audience of experienced developers. These are run as a sponsored text ad clearly marked in the newsletter. We do not do sponsored reviews.</p>
</section><section><h2>Submit a tool</h2>
<p>Email <a href="mailto:hello@console.dev">hello@console.dev</a> with the details and we&#39;ll happily take a look.</p>

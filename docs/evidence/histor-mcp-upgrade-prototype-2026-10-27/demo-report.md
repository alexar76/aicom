- [ ] search\_docs: Проверить сохранённые входы, обязательные поля и типы; добавить граничный пример\.
- [ ] search\_docs: Повторить обработку результата: проверить поля и типы, которые читает сценарий\.

**export\_brief: Изменён**

- destructiveHint: false → true. Это заявление сервера.
- readOnlyHint: true → false. Это заявление сервера.

**legacy\_fetch: Удалён**


**search\_docs: Изменён**

- Новые обязательные поля: workspace
- Изменения type: $/properties/limit, $/properties/workspace
- inputSchema: $\.&quot;properties&quot;\.&quot;limit&quot;\.&quot;type&quot;, $\.&quot;properties&quot;\.&quot;workspace&quot;\.&quot;type&quot;, $\.&quot;required&quot;\[1\]
- outputSchema: $\.&quot;properties&quot;\.&quot;items&quot;\.&quot;type&quot;, $\.&quot;properties&quot;\.&quot;results&quot;\.&quot;type&quot;
- Описание удалено: “using”
- Описание добавлено: “in”
- Описание удалено: “query\.”
- Описание добавлено: “selected workspace\. Include source links in the result\.”

## Границы разбора

- Сравниваются наблюдавшиеся определения, не фактическое поведение сервера.
- Изменение не доказывает поломку; отсутствие изменений не подтверждает безопасность.
- Рабочие сценарии связаны по явно выбранным инструментам, без семантического анализа.
- Размер компактного JSON в UTF-8 — байты, не токены, деньги или фактическая экономия.
- launch отображается только хешем; условия не исполняются и секреты окружения не выводятся.

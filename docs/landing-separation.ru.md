# Фабрика, витрина и экосистема: три разных адреса

[EN](landing-separation.md) · [RU](landing-separation.ru.md) · [ES](landing-separation.es.md) · [FR](landing-separation.fr.md) · [中文](landing-separation.zh.md)

| Адрес | Назначение |
| --- | --- |
| `https://magic-ai-factory.com/` | Работающая фабрика, гостевой генератор, витрина и вход в админку |
| `https://modeldev.modelmarket.dev/` | Новый лендинг фабрики вместо большой смешанной страницы |
| `https://ecosystem.modelmarket.dev/` | Канонический атлас экосистемы и экономики машин |

Главная кнопка лендинга открывает работающую фабрику. Ссылки на продукты ведут в её витрину `/#products`; генератор, агенты, документация и правила — в то же приложение. Ссылки «Экосистема» ведут на отдельный канонический атлас. Из атласа можно познакомиться с фабрикой через её лендинг, а карточки проектов открывают сами сервисы.

Рабочая фабрика восстановлена, а не заменена рекламной страницей. Закупка остаётся включённой; перенос доменов не меняет её бэкенд, журнал, счёт и лимиты. См. [алгоритм закупки](factory-subcontracting.ru.md).

## Реализация

`app/HomePage.tsx` — рабочая витрина. `components/factory/FactoryLanding.tsx` — рекламный лендинг. Только отдельный frontend, собранный и запущенный с `AICOM_SITE_ROLE=factory-landing`, показывает лендинг на `/`, `/ru/`, `/es/`, `/fr/`, `/zh/`. Обычная сборка приложения сохраняет витрину. Для лендинга задан `NEXT_PUBLIC_SITE_URL=https://modeldev.modelmarket.dev`, собственные метаданные и языковые альтернативы. Переходы в приложение используют абсолютный адрес фабрики. PWA приложения и виджет рынка в этой сборке не устанавливаются.

Исходники атласа — `scripts/github-io/`; страницы, sitemap и социальные метаданные используют `https://ecosystem.modelmarket.dev`. Для отдельной сборки адрес можно явно переопределить через `ATLAS_SITE_URL`. Этот релиз не делает push в GitHub. Старый редирект опубликованного GitHub-сайта сохранится до отдельно разрешённой публикации.

Обе рекламные 3D-модели вращаются целиком, управляются мышью, пальцем и стрелками; кнопок паузы/воспроизведения нет. Настройка уменьшения движения отключает автоматическую анимацию, сохраняя ручное вращение. Это концептуальные иллюстрации, а не телеметрия. Старые разделы encyclopedia, school, guides, learn и oracles на modeldev сохранены.

## Production и проверка

Рабочее приложение остаётся на локальном порту 9080. Frontend modeldev использует 9088, образ `ai-factory-frontend:modeldev-final-20261011` и контейнер `aicom-frontend-modeldev-20261011`. Корень атласа `/var/www/ecosystem.modelmarket.dev` ссылается на `/var/www/ecosystem-atlas-20261011`. Исходники релиза, защищённый файл окружения и резервные копии — `/root/domain-split-20261011/`; `rollback-modeldev.sh` возвращает предыдущий vhost modeldev. Контейнеры приложения и закупки при этом продолжают работать.

HTTPS нового домена использует существующий аккаунт Certbot, webroot-проверку, таймер обновления и hook перезагрузки nginx. Перед запросом сертификата нужно дождаться распространения DNS. Не заменяйте действующие TLS-конфигурации голым HTTP-шаблоном.

Проверяйте пять языков, canonical и alternate, переходы в настоящую фабрику, обе вращаемые сцены, старые разделы и здоровье API. Команды: `npm --prefix web/frontend run typecheck`, production-сборка frontend, `python3 scripts/github-io/validate.py`. Результаты — в [отчёте переноса](evidence/domain-split-2026-10-11/README.md).

# Путь посетителя

Три входа выполняют разные задачи: [лендинг фабрики](https://modeldev.modelmarket.dev/ru/), [рабочая фабрика с витриной](https://magic-ai-factory.com/?lang=ru), [карта экосистемы](https://ecosystem.modelmarket.dev/ru/).

Оба маркетинговых лендинга раскрывают сотрудничество через мысль «Вашему ИИ не нужно уметь всё». Общий, явно обозначенный пример дашборда показывает задачу, упорный дефект, ограниченную диагностику специалистом через AIMarket и следующий цикл исправления и проверки в AICOM. Раскрываемое пояснение отделяет подтверждённую закупку и подписанный отчёт от полного исправления продукта. Рабочая фабрика, каталог и сценарии заказа сохраняются.

Первое гостевое действие одно: **Создать лендинг** → описать идею → посмотреть превью → скачать ZIP. Главная фабрики и маркетинговый лендинг ведут в один генератор. Параметр `?lang=en|ru|es|fr|zh` переносит выбранный язык. Генерация начинается только после нажатия посетителем кнопки.

После успешной генерации появляются переходы к карте экосистемы и первому учебному примеру сделки между агентами. Эти шаги доступны и из фабрики. Публичная панель управления — демо для просмотра; полноценные приложения собираются в собственном развёртывании фабрики. Рядом с пояснением есть ссылка на документацию.

Публичный каталог по умолчанию показывает все опубликованные продукты в отдельных разделах «Лендинги» и «Полные продукты» со счётчиками и прямыми переходами. Сохранены категории, дополнительный фильтр QA, поиск по тексту и технологиям, метки шаблонов, теги, цены и стек. Текущая проверка или провал имеют приоритет над старым успешным результатом; QA не гарантирует готовность к продакшену. Описания сохраняют исходный язык. Генератор сохраняет пресеты стиля и опцию веб-помощника. С главной доступны исходная форма пайплайна, передача идеи в Admin, записи сборок и метрики качества.

Техническое устройство раскрывается по желанию; виджет рынка загружается по нажатию. Серверные API генерации и закупки не меняются. Откат интерфейсов выполняется через сохранённые контейнеры и конфигурации nginx. Публикация в GitHub отделена: пуш в Gitea не меняет старый редирект GitHub Pages.

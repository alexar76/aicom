# Recorrido del visitante

Tres entradas distintas: [presentación de la fábrica](https://modeldev.modelmarket.dev/es/), [fábrica y catálogo](https://magic-ai-factory.com/?lang=es), [mapa del ecosistema](https://ecosystem.modelmarket.dev/es/).

Las dos páginas de presentación explican la colaboración con «Tu IA no tiene que saber hacerlo todo». Un ejemplo de panel, identificado como ilustrativo, recorre el encargo, un defecto persistente, un diagnóstico acotado mediante AIMarket y el siguiente ciclo de reparación y pruebas de AICOM. La explicación desplegable distingue la compra y el informe firmado verificados de una reparación completa. Se conservan la fábrica operativa, el catálogo y los flujos de pedido.

El primer paso es **Crear una landing** → describir una idea → revisar la vista previa → descargar ZIP. La presentación y la fábrica usan el mismo generador. `?lang=en|ru|es|fr|zh` conserva el idioma. La generación solo empieza al pulsar su botón.

Tras generar, aparecen enlaces al mapa y a la primera lección de transacciones entre agentes. También están disponibles desde la fábrica. El panel público es una demo de solo lectura; las aplicaciones completas requieren una fábrica propia. La documentación está enlazada junto a esta explicación.

El catálogo muestra todos los productos publicados por defecto, separados en Landing pages y Productos completos, con contadores y enlaces directos. Se conservan categorías, filtro QA opcional, búsqueda por texto y tecnología, plantillas, etiquetas, precios y stack. Los fallos o revisiones actuales prevalecen sobre resultados antiguos; QA no garantiza preparación para producción. Las descripciones conservan su idioma. El generador mantiene estilos y asistente web opcional. La portada permite acceder al formulario del pipeline, enviar ideas a Admin, ver replays y métricas de calidad.

Los detalles técnicos se despliegan a petición; el widget del mercado solo se carga al abrirlo. Las API de generación y contratación no cambian. El rollback usa contenedores y configuraciones nginx conservados. Un push a Gitea no cambia el antiguo redireccionamiento de GitHub Pages.

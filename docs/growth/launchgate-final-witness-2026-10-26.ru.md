# Launch Gate — финальная проверка числовой подсказки

26 октября 2026. Серия завершена: последний сравнительный прогон на Linux factory-vps, без новых случаев и последующей подгонки.

Взяты **все пять ранее удержанных живых контекстов**: два возникли из естественных ошибок, три — из контролируемых начальных ошибок; четыре разных параметрических случая. Для каждого сохранены последний неверный ответ и полный породивший его запрос. До вызовов модели зафиксированы прогнозы, обе версии SDK, сообщения и порядок.

## Результат

| Проверка | Прежнее сообщение | Новое числовое сравнение |
|---|---|---|
| Исправление известных ошибок | **6/40**, 34 удержаны | **40/40**, удержаний нет |
| Сохранение искусственно заданных правильных ответов | **20/20** | **20/20** |

В парных блоках 34 исправления произошли только с новой подсказкой, 6 — в обеих группах. Разница 85 процентных пунктов **на этой выбранной группе**. Каждый из пяти контекстов с новой подсказкой прошёл 8/8; прежние результаты по контекстам 5/8, 0/8, 0/8, 1/8, 0/8. Естественное происхождение: 5/16 →16/16; контролируемое: 1/24 →24/24. Эти происхождения не превращаются в новую независимую выборку.

Все прогнозы выполнены: >=32/40 новых исправлений (40), преимущество >=8/40 (34), >=19/20 сохранённых правильных в каждой группе (20). Все 86 выданных результатов повторно проверены арифметически, без SDK-валидатора. 34 неверных продолжения прежней группы удержаны, уведомления есть во всех 120 кадрах. Ошибок API, исключённых результатов или повторного исследования нет.

Менялось только последнее сообщение проверки. Каталог уже содержал числа; новая подсказка явно связывает выбранное и лучшее значение с записями. Проверено целое сообщение, включая ссылку на оптимальную запись, а не вклад отдельной фразы. Причина внутренней ошибки модели этим не установлена. Контрольные правильные ответы сконструированы; их сообщения между номинальными группами одинаковы.

Это одно отдельное исследовательское продолжение от ранее удержанного ответа, **не третий проход в продукте**. Продуктовый лимит двух исправлений не менялся. Исследованы пять известных проблем, а не новый holdout, надёжность на развёртывании, общая защита от инъекций или эффективность подсказки о неполном множестве. Автор и аудит с AI, неслепые; сторонний native GUI не проверялся.

## Стоимость и сохранность

120 новых вызовов: по usage вне пика **$0,012380472**, консервативный учёт **$0,024760944**. Вместе с предыдущим перспективным прогоном — **$0,041314905** по временному тарифу / **$0,082629810** консервативно, ниже общего лимита $0,15. Счёт/баланс не запрашивались. Сервер существующий.

До API на Linux прошли 8 тестов исследования, 28 relay/бюджета/сбора и 120 preflight. Ключ и сеть только у серверного relay. Все запросы и ответы сохранены, 253 хеша проверены до удаления временного каталога. Без автоповторов и потери данных. Код продукта во время сравнения не менялся; предшествующие 798 тестов остаются его проверкой.

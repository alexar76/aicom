# Arhan: что менялось у исходных 2 036 MCP-серверов

Подсчёт выполнен 25 октября 2026 на Linux admin-vps. Данные — **замороженный снимок
HISTOR от 20 октября**, изменения с `2026-09-24T10:53:44Z` по
`2026-10-20T00:31:28Z`. Новых опросов серверов в этом исследовании не было.

**Ответ на вопрос Arhan:** у **1 994 из 2 036 серверов — 97,94% —** было хотя бы
одно наблюдавшееся изменение верхнего описания tool сверх цифр и пробельных символов.
У 39 в этой части описаний менялись только цифры с возможными пробелами,
у 3 — только пробелы. Это классификация текста, а не оценка вредоносности или
семантической значимости.

## Серверы и события — два разных знаменателя

В исходной статье 2 036 — число remote-записей, у которых изменилось описание
существующего инструмента. У этих серверов всего **7 319 событий изменений**;
из них **5 482** затрагивают такое описание. Все 5 482 доступны для сравнения
полных состояний до и после.

| Что менялось в верхних описаниях существующих tools | События из 5 482 | Доля событий | Серверы из 2 036¹ |
|---|---:|---:|---:|
| Текст сверх цифр и пробелов | 5 014 | 91,46% | 1 994 |
| Только цифры, допускаются сопутствующие пробелы | 462 | 8,43% | 39 |
| Только пробелы/переносы/отступы | 6 | 0,11% | 3 |
| **Всего** | **5 482** | **100%** | **2 036** |

¹ Для серверов действует приоритет за весь период: хотя бы один текстовый переход
→ первая строка; иначе хотя бы один числовой → вторая; иначе пробелы → третья.
Число серверов — не число независимых операторов. Описания новых/удалённых tools
не считаются редактированием описания существующего tool.

В остальных 1 837 событиях верхнее описание не менялось либо полное сравнение
недоступно. В полной истории есть **12 names-only событий у 6 серверов**: нельзя
классифицировать их текст и схемы по отсутствующим blobs. Все шесть серверов уже
имеют подтверждённые текстовые правки, поэтому эти пропуски не меняют разрез
1 994 / 39 / 3. Это не доказательство полноты истории между опросами.

## Описания, схемы и состав tools

Ниже независимые признаки по **всем 7 319 событиям исходной группы**. Строки
пересекаются: один переход может менять текст, схему и набор инструментов.

| Подтверждённый признак по полным состояниям | События | Серверы |
|---|---:|---:|
| Верхнее description существующего tool | 5 482 | 2 036 |
| Description внутри сопоставимых узлов схемы² | 2 815 | 1 283 |
| Любая правка inputSchema, включая её descriptions | 3 627 | 1 491 |
| Любая правка outputSchema, включая её descriptions | 1 378 | 531 |
| Структура/ограничения/прочие контрактные поля схемы | 3 033 | 1 187 |
| Добавление/удаление имени tool | 2 047 | 904 |
| Перестановка уникальных элементов required/enum | 36 | 11 |
| Прочие аннотации схемы: title/examples/$comment | 145 | 93 |

² Включая description в корне схемы. Вложенные описания внутри целиком добавленной
или удалённой ветки отдельно не подсчитываются: это изменение структуры ветки.

Полные состояния отсутствуют у 12 событий; соответствующие флаги — подтверждённый
минимум. По доступным **спискам имён**, включая names-only, состав tools менялся
в **2 053 событиях у 906 серверов**. Разница с raw-строкой — шесть names-only
событий; она не была приписана к известным текстовым или схемным изменениям.

Если требуется строго «в событии менялись только описания», без состава tools,
ограничений, порядка required/enum или прочих аннотаций, таких событий **3 019**:

- 2 595 — текст сверх цифр/пробелов;
- 419 — только числа с возможными пробелами;
- 5 — только пробелы.

Здесь учитываются верхние и схемные descriptions. Если разрешить правки **только
верхних описаний**, сохранив inputSchema/outputSchema и состав tools точно,
получается **2 016 событий: 1 639 текстовых, 372 числовых, 5 пробельных**.

Поэтому 462 числовых перехода из первой таблицы нельзя назвать 462 полностью
косметическими изменениями интерфейса: в 90 из них менялось ещё что-то. Аналогично
из 39 «числовых» серверов лишь **27** за всю известную историю меняли исключительно
числа/пробелы в верхних описаниях при неизменных схемах и составе tools. Ещё **2**
сервера всю историю меняли только пробелы в верхних описаниях.

## Непересекающиеся категории всех событий

Для проверки суммы каждому из 7 319 событий присвоена одна основная категория.
Приоритет: состав → контрактные поля схемы → текст → числа → порядок
required/enum → прочие аннотации → пробелы. Независимые флаги выше сохраняют
смешанные случаи.

| Основная категория | События |
|---|---:|
| Добавление/удаление tools, с возможными другими правками | 2 047 |
| Контрактные поля схемы, без изменения состава | 2 205 |
| Текст descriptions сверх цифр/пробелов, без двух предыдущих | 2 606 |
| Числовые descriptions, без более приоритетных изменений | 422 |
| Порядок required/enum, без более приоритетных изменений | 20 |
| Только прочие аннотации схемы | 2 |
| Только пробелы в descriptions | 5 |
| Полное сравнение недоступно | 12 |
| **Всего** | **7 319** |

Основная категория «числовые descriptions» не равна строгому «только числа во всём
событии»: три из 422 содержат также другие аннотации/порядок. Аналогично категория
текста может сочетаться с этими менее приоритетными признаками. Для строгого
критерия используются 419 и 2 595 из предыдущего раздела.

## Пограничные примеры

Пять публичных API-ссылок проверены без авторизации: HTTP 200, ID, время и оба
digest совпадают со снимком. Исходные ответы сохранены в evidence.

| Изменение | Категория и смысл |
|---|---|
| [#13185](https://histor.modelmarket.dev/api/v1/changes/13185): цена в description `$0.002` → `$0.02` | Чисто числовая правка, при этом заявленная цена выросла в десять раз. Автоматически исключать её из review нельзя. Это наблюдение текста, не проверка фактического биллинга. |
| [#15587](https://histor.modelmarket.dev/api/v1/changes/15587): срок trial `14` → `30` дней | Тоже числовая правка с возможным изменением условий использования. |
| [#8738](https://histor.modelmarket.dev/api/v1/changes/8738): переносы и отступы | Строго пробельный переход верхних описаний; схемы и состав неизменны. |
| [#369](https://histor.modelmarket.dev/api/v1/changes/369): порядок двух enum-значений | Отдельная механическая категория порядка, не изменение множества допустимых значений. Влияние на выбор модели не измерялось. |
| [#3336](https://histor.modelmarket.dev/api/v1/changes/3336): добавлено свойство `existingRepo`, изменено описание workflow | Смешанная правка схемы и текста, а не только редактура описания. |

Маска чисел полезна как дополнительный вид diff для читателя. **Алгоритм trust digest
не менялся**: числа, исходный текст и схемы сохраняются в проверяемом содержимом.
Даже whitespace-only — механический признак, а не доказательство одинакового
смысла; текстовая категория также включает обычные опечатки и перефразирование.

## Что сравнивалось и как проверено

Восстановлена исходная база 10 929 remote-записей по критерию исходной статьи:
не stdio, не delisted, непустые toolSetDigest/firstPinned, firstPinned не позднее
конца 24 сентября. Когорта 2 036 отбиралась по исходному summary-признаку верхнего
description, затем классифицировалась заново по **полным** toolsets. Обрезанные
summary не использовались для определения вида текста/схемы.

Полный протокол зафиксирован до подсчёта. Whitespace удаляется только для
сравнения; числовая маска заменяет существующие последовательности десятичных
цифр, сохраняя остальные символы и пунктуацию. Description распознаётся только
в действительных узлах схемы; `description` внутри default/enum — буквальные
данные, внутри properties может быть именем параметра. `$schema`, `$id`, `$ref`,
defaults и неизвестные ключи не объявляются косметикой. Массивы схем сравниваются
по позициям, автоматически не сортируются.

Измеряются четыре поля исходного digest: name, description, inputSchema,
outputSchema. Порядок tools и ключей JSON уже устранён канонизацией; обычное
переформатирование JSON не породило бы такое событие. Прочие поля MCP этим
разрезом не покрываются.

- Все три входных gzip сверены с SHA-256 закреплённого manifest.
- **14 869 из 14 869** нужных уникальных toolsets найдены и повторно проверены
  собственным канонизатором HISTOR. Для самой когорты 2 036 требовалось 9 006.
- На доступных полных переходах расхождений raw-флагов с summary нет.
- **20 unit tests прошли на Linux**: длинные описания, смешанные изменения,
  свойства с именем description, literal/default/enum, bool/int, outputSchema,
  перестановки и schema dialect/reference.
- Независимый сценарий пересчитал экспортированные JSONL и подтвердил суммы,
  знаменатели, флаги и hashes. Это проверка агрегации, не второе независимое
  воспроизведение классификации по raw blobs внешним исследователем.
- 5 277 соседних пар с непустыми digest состыкованы, разрывов нет; ещё 6 пар
  содержат null и не устанавливают непрерывность содержимого между наблюдениями.

Выполнение: Linux amd64, Python 3.11.2, Docker/runc без сети, read-only входные
данные, UID 65532, без capabilities, лимиты 1 CPU / 1 536 MiB. gVisor/runsc на
admin-vps не зарегистрирован: первая попытка вернула 125 до исполнения кода.
Пакеты и MCP-серверы не запускались, продакшен-БД не читалась.
Скачанные результаты дополнительно сверены с удалёнными по SHA-256; собственный
временный каталог на VPS удалён, исходный публичный снимок не изменялся.

Отдельная net-проверка самого раннего записанного состояния до изменения против
последнего после: **2 028 серверов имеют различие, 5 вернулись к тому же полному
toolset, 3 не имеют обеих доступных границ**. Это не замена счёта переходов:
сервер мог изменить текст, а потом вернуть его. Верхние описания отличаются на
границах у 1 975 серверов, тогда как хотя бы одно изменение было у всех 2 036.

Старое число **2 719** воспроизведено отдельно: это другая diff-ops эвристика по
всем 23 821 событиям, включая packages и remote вне исходной когорты. Оно не
является числом «косметических серверов» и не вычитается из 2 036 или 5 482.

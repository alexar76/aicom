## MCPMoat рассматривает WARDEN как ближайший аналог

В [документе сравнения](https://github.com/Ducarv/mcpmoat/blob/fc776bc2eb10376994b6d021a18f6230487bc033/docs/competitors.md#L112), датированном **23 октября**, `alexar76/warden` назван ближайшим по возможностям инструментом. Среди [идей для перенятия](https://github.com/Ducarv/mcpmoat/blob/fc776bc2eb10376994b6d021a18f6230487bc033/docs/competitors.md#L142) WARDEN прямо указан источником:

- фиксации версии и хеша набора правил в отчётах;
- показа изменений закреплённых tools по полям и словам;
- разделения серьёзности замечания и блокировки;
- ясного описания ограничений;
- публикации методики измерений с отложенной тестовой выборкой.

Это документальное свидетельство изучения наших подходов другим проектом. Автор оговаривает: инструменты не устанавливались и не запускались, результаты тестов не воспроизводились. Внедрение WARDEN этим не подтверждается.

[Задачу №32](https://github.com/Ducarv/mcpmoat/issues/32) открыл Ducarv 17 октября; [PR №111](https://github.com/Ducarv/mcpmoat/pull/111) принят 23 октября в 18:49 МСК. История коммита также отмечает AI соавтора.

Текущая версия привязана к commit `fc776bc2eb10376994b6d021a18f6230487bc033`; SHA-256 текста `6a815d0d11b3b855d29990ef4995bca806a627f4ef4609e22eebfeebc375f638`. ## Воспроизводимость

Проверялись ссылки внутри найденных публикаций, документы за пределами README, issue/PR, родные формы литературных каталогов и комментарии. Поиск включал языковые варианты и точные домены, пакеты, названия и уникальные фразы. Это ограниченный проход публичных источников; закрытые сообщества и полный индекс всех региональных поисковиков не охватывались.

Выполнены 80 различных web-запросов и 14 запросов GitHub search: восемь по README и шесть по issue. Дополнительно проверялись родные поиски каталогов и HN. В HTTP-индексе 76 прямых GET, все с ответом 200; поисковые API входят в это число, поэтому числа запросов и HTTP-чтений не суммируются как отдельные проверки.

Общий [индекс запросов и HTTP-чтений](../../artifacts/ecosystem-chains-2026-10-28/verification-index.json) содержит URL, время, статус и SHA-256. Повторные чтения одного URL учитываются отдельно. Публикаций, заявок, сообщений, изменений аккаунтов и GitHub writes в этом проходе не было.

## Внешний manifest проходит нашу проверку AIMarket v2

У Industrial Platform Sentinel доступны [discovery JSON](https://x402-gateway-production-1f21.up.railway.app/.well-known/ai-market.json) и [manifest](https://x402-gateway-production-1f21.up.railway.app/ai-market/v2/manifest). Оба прочитаны **28 октября около 17:11 МСК**, HTTP200. Заявлены protocol v2 и четыре бесплатные bootstrap-capability.

Захваченный manifest проверен локально нашей `manifest_canonical` из [signing.py](/Users/alex/Desktop/ai_tests/aicompany/aicom/web/backend/services/ai_market_protocol/signing.py:150): **подпись Ed25519 корректна**. Контрольное изменение цены первого инструмента на 0,01 приводит к отклонению подписи. Из backend извлечена только чистая функция через AST; приложение и чужой код не запускались.

Это подтверждает совместимость конкретного снимка с нашей канонизацией и ключом, указанным в самом manifest. Оно не устанавливает личность оператора, партнёрство, регистрацию в нашем Hub, работоспособность invoke, платные вызовы или полное соответствие протоколу. Четыре capability объявлены; их исполнение не проверялось.

В [публичном исходнике адаптера](https://github.com/industrial-platform-ai/industrial-platform-agent-tools/blob/main/gateway/aimarket-federation.mjs) воспроизведены характерные правила Python JSON и состав подписываемой строки. Факт исправления health в production не утверждается. Точных ссылок на alexar76/modelmarket.dev в прочитанном внешнем тексте нет; связь установлена через специфический формат и проверяемую совместимость manifest.

## Trovark снял оценку AIMarket Plugins из-за неполноты своего анализа

[Комментарий автора Trovark](https://github.com/lets-order-some-fries/trovark/issues/22#issuecomment-5682361982) от **15 сентября 17:49 МСК** прямо включает `alexar76/aimarket-plugins` в проверку покрытия оценщика. В описанной перепроверке оценка сменилась с **B−72 на INSUFFICIENT DATA**. Автор сообщил о сравнении до/после на 381 репозитории; наша карточка оказалась единственной, для которой оценку полностью отозвали. Текущее состояние публичной карточки отдельно не проверялось.

Причина — неполный набор прочитанных исходников, включая `gateway_core.py`. Исправление Trovark принято [в PR25](https://github.com/lets-order-some-fries/trovark/pull/25) **25 сентября**. Это внешнее измерение качества сбора сведений оценщиком. Оно не устанавливает уязвимость AIMarket Plugins.

[Метод Trovark](https://github.com/lets-order-some-fries/trovark/blob/73f44c42a17e0cafedea31650d6b218db2d34d9e/README.md#L9) — статический анализ публичных исходников без исполнения серверного кода. Упомянутые повторные запуски CLI относятся к самому оценщику; вызов нашего MCP не заявлен. Числа 125, затем исправленные 121 tools в обсуждении относятся к GitHub MCP Server, а не к AIMarket Plugins. Анализ автора нами не воспроизводился; PR отмечает AI соавторство.

Уже известный MCPMoat дополнительно называет WARDEN среди сильных конкурентов в [PRD, строка 1004](https://github.com/Ducarv/mcpmoat/blob/fc776bc2eb10376994b6d021a18f6230487bc033/docs/PRD.md#L1004). Это ещё один документ того же проекта, не вторая независимая рекомендация.

Например, подробный diff tools действительно реализован, но соответствующую задачу открыли **17 октября**, до обзора от 23 октября. Advisory label также не гарантирует отсутствия блокировки: применяются пороги `--fail-on`.

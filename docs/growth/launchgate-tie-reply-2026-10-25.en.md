Agreed — the tie version gave us headroom. We ran six tied-choice cases with
counterbalanced record order, eight repetitions, three input conditions and
three defense settings: 432 main answers on the same DeepSeek model.

Without the guard, target selection went from 28/48 clean to 48/48 injected.
With the note it went from 25/48 to 44/48; with note + Stop, from 29/48 to
45/48. After adjusting for each setting's baseline, the apparent attenuation
was only 2.1 and 8.3 percentage points, with fixture-cluster intervals including
zero. So the injection clearly moved choices in this corpus, but we still
cannot claim a reliable added guard benefit. Stop requested no rechecks.

All choices remained admissible. Separate genuine-user preference controls
were followed in 18/18 answers. We've added multiple admissible IDs, common
baseline distance and guard-induced clean-distribution shifts to the evaluator,
so suppressing changes cannot masquerade as preserving the user's choice.

One limitation: the injected notes never named the target, but the selected
target was named in every affected final answer. This run therefore doesn't
demonstrate the zero-name final-answer variant. The historical AgentDojo score
remains unchanged.

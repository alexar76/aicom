## Полнота поиска и списков API

Повторная проверка DEV выявила конкретное ограничение: публичный список `articles?username=alexar76&per_page=100` всё ещё возвращает 59 статей с последней датой 25 октября, хотя [статья от 27 октября](https://dev.to/alexar76/same-mcp-version-different-tools-what-two-independent-captures-revealed-2p6d) доступна прямым запросом и имеет ноль комментариев. По ID новой статьи API в одном запросе вернул 404, тогда как [канонический API-путь](https://dev.to/api/articles/alexar76/why-our-mcp-server-stopped-trusting-localhost-by-default-26jm) ответил 200, подтвердил публикацию от alexar76 28 октября в 15:01 МСК и ноль комментариев.

Причина расхождения не установлена. Для выводов об отсутствии страницы нельзя полагаться на один список или один маршрут API. Числа комментариев из первого отчёта относятся к прочитанной тогда выборке; они не устанавливают полноту всего аккаунта. [Свидетельства списка](../../artifacts/ecosystem-global-2026-10-28/root/dev-live-scope-check.json) и [прямого маршрута](../../artifacts/ecosystem-global-2026-10-28/root/dev-new-article-route-check.json) сохранены отдельно. Сегодняшняя статья слишком свежая, чтобы считать отсутствие поисковой индексации показателем интереса аудитории.

Позднее [углублённая проверка около 16:30 МСК](external-deep-2026-10-28.ru.md) закрыла пробел чтением авторского API: 61 опубликованная статья, все 12 непустых веток и 140 комментариев.

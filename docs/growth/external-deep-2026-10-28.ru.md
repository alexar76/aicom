## HISTOR в научных индексах

[OpenAlex W7223029314](https://openalex.org/W7223029314) содержит HISTOR как dataset с названием снимка от 20 октября. Запись создана **21 октября**, импортирована через DataCite; `cited_by_count=0`. Запрос [по version DOI](https://api.openalex.org/works/https://doi.org/10.5281/zenodo.23512760) возвращает запись с concept DOI `10.5281/zenodo.23512759`. Это дополнительная научная индексация, не новая исследовательская цитата.

У обеих записей DataCite счётчик цитирований — ноль; обратный поиск зарегистрированных связей вернул только собственную concept-запись. Europe PMC не вернул результатов по точному DOI, Semantic Scholar ответил 404. Последнее означает отсутствие доступной записи в этом API, а не доказанное отсутствие публикаций.

Hugging Face показывает 111 downloads, ноль likes и одну дискуссию от parquet-converter BOT. Поиск точного имени вернул собственный датасет. Счётчик скачиваний не устанавливает число пользователей или применение в исследованиях. Известное [использование и сверка Paraphern/RugSnare](https://github.com/Paraphern/rugsnare) остаётся содержательным внешним свидетельством: нулевые счётчики научных индексов его не отменяют.

[Подробная проверка индексов](../../artifacts/ecosystem-deep-2026-10-28/citations/research-summary.md) и [факты OpenAlex](../../artifacts/ecosystem-deep-2026-10-28/citations/openalex-fact.json) содержат точные маршруты, время, статусы и хеши ответов.

## Область и ограничения прохода

Выполнены 75 web-запросов, включая один поиск документации deps.dev, и девять запросов GitHub repository search. У 72 web-запросов сохранены полные ответы поискового инструмента; три начальных запроса внешнего использования записаны только текстом и не используются как самостоятельное воспроизводимое доказательство. В HTTP-индексе — 89 отдельных публичных чтений, включая GitHub search и 12 веток DEV; повторные чтения одного URL учитываются отдельно. Авторское чтение списка DEV отдельно использовано для установления области опубликованных статей.

Научная часть включает точные DOI, имена файлов датасета, поиски notebook/Colab/Kaggle/GitLab и национальные научные площадки: HAL, J-STAGE/CiNii, CNKI, arXiv, eLibrary/CyberLeninka, SciELO и ScienceON. Использовались русские, китайские, японские, корейские, испанские и португальские термины. Литературная часть проверяла точные названия и их ES/FR/ZH варианты; техническая — в том числе FR/DE/ES/PT формулировки и уникальные числа исследований.

Это целевые запросы и публичные API, а не полный просмотр национальных баз, всех поисковиков, закрытых групп или всего интернета. Нулевые результаты относятся к конкретным запросам; импорт каталогов, собственные публикации, зеркала и счётчики не выдаются за независимое внедрение. Общий [журнал запросов и прямых чтений](../../artifacts/ecosystem-deep-2026-10-28/verification-index.json) фиксирует границы проверки.

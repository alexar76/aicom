# 访客流程

三个入口各有用途：[工厂介绍](https://modeldev.modelmarket.dev/zh/)、[工厂与作品目录](https://magic-ai-factory.com/?lang=zh)、[生态地图](https://ecosystem.modelmarket.dev/zh/)。

两个营销页面通过“你的 AI 不必无所不能”介绍协作。一个明确标注为示例的数据看板流程展示需求、顽固缺陷、通过 AIMarket 购买范围明确的专家诊断，以及 AICOM 下一轮修复和测试。可展开的说明区分已验证的生产采购与签名报告和完整产品修复。实际工厂、目录及订购流程保持完整。

第一步是**创建着陆页** → 描述创意 → 查看预览 → 下载 ZIP。介绍页和工厂使用同一个生成器。`?lang=en|ru|es|fr|zh` 保留语言选择。只有访客点击生成按钮后才开始生成。

成功生成后，页面提供生态地图和智能体首笔交易课程的链接。工厂页面也提供这些入口。公共控制台是只读演示；构建完整应用需要自行部署工厂。说明旁边提供文档链接。

公共目录默认展示所有已发布产品，分为“着陆页”和“完整产品”，提供数量和直接跳转。保留分类、可选 QA 筛选、文本和技术搜索、模板标记、标签、价格和技术栈。当前失败或审核优先于旧的通过记录；QA 不保证生产就绪，描述保留原语言。生成器保留风格预设和可选网页助手。首页可访问原工厂流水线表单、向 Admin 传递创意、构建回放和质量指标。

技术说明按需展开；市场组件仅在打开时加载。生成与采购后端 API 保持不变。通过保留的容器和 nginx 配置可以回滚。推送至 Gitea 不会改变旧的 GitHub Pages 重定向。

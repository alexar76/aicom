# Нагрузочное тестирование: результаты 2026-10-23, до и после

**Языки:** [English](load-testing.md) · Русский · [Español](load-testing.es.md) · [Français](load-testing.fr.md) · [中文](load-testing.zh.md)

Как публичный флот ведёт себя под нагрузкой, как денежный путь ведёт себя при конкуренции, что было
медленным и почему, и что изменилось. Все цифры измерены 2026-10-23; команды для повтора — в конце.

## Что запускали

| Тест | Инструмент | Цель | Нагрузка |
|---|---|---|---|
| Публичный smoke | Locust 2.46.5, `scripts/load/run_load_smoke.sh` | живой флот (только чтение) | 8 пользователей, 90 с |
| Публичный constant | то же | живой флот (только чтение) | 20 пользователей, 10 мин |
| Денежный путь | `aimarket-hub/scripts/load_money_path.py` | локальный хаб, SQLite и PostgreSQL | 2 300 запросов, 64 одновременно |
| Soak фабрики (KI-3) | `scripts/load_test_factory.sh` | локальный бэкенд фабрики, 4 воркера uvicorn | 10 потоков, 15 мин |

Публичная смесь только читает: здоровье фабрики, каталог и полоса доверия, витрина, поиск, статистика
и discovery хаба, mesh, ARGUS, monitor и pulse. Платных вызовов она не делает; денежный путь
проверяется на локальном хабе.

## Денежный путь на локальном хабе

Платные вызовы с многих аккаунтов, каждый платный вызов трижды одновременно повторён под одним
`Idempotency-Key`, регистрации наперегонки за бюджет грантов $0,25; затем аудит леджера.

| База | Запросов | Одновременно | Пропускная способность | p95 | Леджер после прогона |
|---|---|---|---|---|---|
| SQLite | 2 300 | 64 | 80 запр/с | 2,3 с | все инварианты сходятся; 100 групп с ключом списаны по одному разу; гранты остановились на $0,25 |
| PostgreSQL 18 | 2 299 | 64 | 41 запр/с | 4,3 с | то же; один обрыв соединения, по аудиту не списан |

Инварианты: удержанная сумма аккаунта равна сумме его удержанных холдов (и после прогона равна нулю),
деньги не появляются и не пропадают, каждая группа с ключом списана ровно один раз.

## Что было медленным и что изменилось

| Где | Причина, измерено | Изменение |
|---|---|---|
| Воркер конвейера | 92% его CPU — `yaml.safe_load`: конфиг перечитывался для каждого продукта в каждом цикле (py-spy, живой процесс) | разбор переиспользуется, пока не меняется ни один файл конфигурации (mtime, размер, inode) |
| Витрина `/api/products` | 57 оценок демо на 19 продуктов, каждая обходит дерево продукта вместе с `node_modules`: 5,1 с из 5,4 с | обход отсекает вендорные каталоги; одна оценка на продукт за запрос; готовая витрина живёт 30 с и пересобирается сразу, как только конвейер пишет состояние |
| Полоса доверия | 4 с уходило на загрузку всех 3 510 задач фабрики ради подсчёта статусов продуктов | чтение только продуктов (0,4 мс); кэш на минуту; сборка вне event loop |
| `/api/health` фабрики | event loop стоял за полосой доверия | работа вынесена в поток |
| Супервизор KI-3 | проверку здоровья учитывал и отклонял лимитер по адресу | проверка не учитывается; 403/429 считается «жив» |
| Monitor | 17 опросов спутников блокирующим HTTP-клиентом в event loop | один рабочий поток; **выкачено 2026-10-23** |
| Логи хаба | 311 трейсбеков в день от леджеров ACEX, выключенных конфигурацией | одно предупреждение на леджер; те же ответы 503 |
| Директор | один пустой ответ модели выбрасывал весь цикл поиска идей | сбойное обогащение остаётся пустым |

## Как повторить

```bash
LOAD_TARGET=public LOAD_MODE=smoke ./scripts/load/run_load_smoke.sh
LOAD_TARGET=public LOAD_MODE=constant ./scripts/load/run_load_smoke.sh
python aimarket-hub/scripts/load_money_path.py --invokes 2000 --concurrency 64
python aimarket-hub/scripts/load_money_path.py --invokes 2000 --concurrency 64 --database-url postgresql:///scratch_db
./scripts/load_test_factory.sh --base-url http://127.0.0.1:9081 --duration 900 --concurrency 10
```

Прогон на PostgreSQL стирает схему переданной базы. Методика, режимы и критерии:
[`scripts/load/METHODOLOGY.md`](../scripts/load/METHODOLOGY.md). Прежние прогоны:
[`scripts/load/RESULTS-2026-09-14.md`](../scripts/load/RESULTS-2026-09-14.md).
